## 业务流如何跑

采购维护价格 → 工程确认BOM/计量/工时 → 项目负责人确认投入分摊 → 核算人员刷新并核算 → 主管确认提交 → 销售导出客户报价 → 客户确认 → 标准销售报价/销售订单 → 采购与生产 → 交付、开票、收款。

当前成本报价功能提供内部核算和客户Excel导出，未发现自动生成标准销售报价或销售订单的入口。前半段已验证；后半段目前需手工交接，未完成采购、生产、交付、财务的端到端测试。

如需系统自动衔接，需另开发并验收：已确认成本报价生成销售报价/订单，绑定报价版本与客户选定数量档，映射最终价/税率/一次性费用，并校验客户、公司、币种和重复转换。不能将内部完整核算表发给客户。
