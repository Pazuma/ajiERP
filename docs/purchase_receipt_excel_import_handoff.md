# 入库清单导入说明

源文件：`sites/aji_test.localhost/private/files/ERP表格模板(2)(1)_入库清单.xlsx`

该工作簿包含 34 条数据和 18 个字段。系统导入表为“入库清单”，目标表单为 `Purchase Receipt`。

- `采购入库`：创建采购入库草稿。
- `采购退料`：创建采购退料草稿，数量按绝对值写入，原始负号保存在 `Excel原始数量`。
- `借样出库`：创建 `Stock Entry / Material Issue` 草稿，避免把出库误记为入库。
- 不存在的物料和供应商会先建立最小主数据；Excel 的物料名称、版本、适用机种、物料类别、库位、送货单、镜片入库单/退料单、对账日期、操作员、总价和来源行号均保存在单据详情中。
- 系统无法匹配的仓库名称不会丢失，实际库存行使用默认仓库，原值保存在 `Excel库位`。

部署后执行一次站点迁移，使 `excel_form_fields.json` 中新增字段生效，然后在库存侧的“采购入库/入库清单”导入窗口上传源文件。导入方式选择“新建记录”，提交前先预览；导入后默认是草稿，可按审批制度批量审核/提交。
