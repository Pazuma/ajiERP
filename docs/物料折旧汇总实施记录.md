## 1. 已实现范围

新增独立标准 Script Report「物料折旧汇总」，入口为「库存 → 报表 → 物料折旧汇总」。

- 折旧规则继续在「物料 → 对应物料 → 折旧物料表」设置，没有新增第二套配置。
- 仅汇总启用自动评估、规则有效、按今天测算累计比例大于0的物料仓库记录。
- 查询时使用当前 Bin 库存数量，复用原 `calculate_assessment`，不回写物料及规则。
- 分列显示原始参考单价、当前库存单价、折旧后参考单价，避免价格口径混淆。
- 显示最后有效使用日期、未使用天数、来源说明及有权限读取的来源单据链接。
- 支持公司、仓库、物料、库存范围、未使用至少天数筛选及原生 Excel/CSV 导出。
- 按公司及币种分别汇总建议金额，不跨单位合计数量，不生成混币总金额。
- 无规则、规则尚未开始、未使用日期未知等状态不以假数据补齐。

只做管理参考，不自动计提、不调库存估值、不改采购价、销售价或报价单。

## 4. 完整业务流

### 4.1 规则维护和原有保存流程

1. 打开对应库存物料，展开「折旧物料表」。
2. 按仓库填写原始参考单价、减值起算日期、免减值月数、周期月数、每周期比例、累计上限，并启用该行自动评估。
3. 原始参考单价必须核对为库存单位、仓库所属公司本位币；当前字段不包含自动币种或单位换算能力。
4. 保存物料，原 Item.validate → assess_item → calculate_assessment 链路按当前数量更新原子表评估结果。
5. 原有 daily → scheduled_assess_items 继续更新启用规则的评估快照；本次未调整调度或验证其队列健康状态。

真正的计算门槛是子表 `auto_assess`，不额外改变父物料开关的原语义。

### 4.2 打开只读汇总

1. 从「库存 → 报表」进入「物料折旧汇总」。
2. 校验报表角色、Item 报表权限、Item/Warehouse/Company 读取权限，再按 User Permissions 生成可读取集合。
3. 只读取允许物料及仓库下的启用规则和当前 Bin；无权读取的记录不出现在明细、异常或汇总中。
4. 排除未启用、停用物料/仓库、组仓库、已计提/转回保护记录；重复规则、负库存、缺失余额或无效配置提示核对。
5. 以今天和当前数量调用原纯计算函数；累计比例大于0才算已开始。未到日期、免减值期内或未满周期不展示。
6. 读取有效销售出库/制造消耗，计算本仓最后有效使用日期和未使用天数；无有效记录留空并注明待确认。
7. 返回只读明细、异常提示、物料数及仓库记录数、分公司币种的建议金额。
8. 需要修改规则时点击物料编码回物料表；新报表不修改任何规则或库存数据。

### 4.3 使用时间口径

- 计入：已提交非退货销售出库、更新库存的销售发票、制造及制造消耗中的实际负库存变动。
- 核对：库存流水与原单据、明细行、物料、仓库必须一致；以有效流水的 posting_datetime 取最近一次。
- 排除：调拨、调入、采购收货/退货、盘点、估值变更、草稿、取消、退货及未来流水。
- 按物料和仓库统计，不把其他仓库使用当成当前仓库使用，不将建档日或折旧起算日当成使用日期。
- 来源单据无读取权限时隐藏单号与链接，仅显示存在有效记录的说明。
- 最近使用不会自动重置折旧起算日期或取消已有折旧。

### 4.4 导出与后续处理

1. 设置筛选，刷新核对明细及异常提示。
2. 从报表原生菜单导出 Excel 或 CSV，复用同一报表服务、筛选和行级权限；另遵守 Item 导出权限。
3. 财务/库存管理人员根据建议金额人工核对。实际调价、财务计提或转回不属于此报表流程。

```text
Item折旧子表维护 ──保存──→ 原assess_item ─→ 原评估快照
                         ↑ 原daily更新（保持）

库存新报表 / 原生导出
  → Frappe Query Report → 新execute → get_summary
  → 角色、读取权限及User Permissions
  → 当前启用规则＋Item＋Warehouse＋Company＋Bin
  → 原calculate_assessment（内存）→ 已开始的有效记录
  → 有效出库/制造消耗 → 最后使用、未使用天数
  → 明细、提示、分公司币种汇总 → 页面 / Excel / CSV
```

## 5. 权限与部署

- 新报表角色为 Stock Manager、Accounts Manager；Administrator 可验证。
- 拥有入口角色不等于拥有基础资料读取权限。当前站点仅 Stock Manager 未必具备 Company 读取，仅 Accounts Manager 未必具备 Warehouse/Item 报表权限；应通过现有角色授权组合补齐，不能为显示报表绕过权限。测试使用 Stock Manager＋Accounts Manager＋Stock User 验证真实 User Permissions。
- 目标站点定向 reload 新 Report，未运行全量 migrate，以免触发工作区其他未发布变更。
- 定向增加 Stock 侧栏链接并放入已有「报表」分组；重复执行两次仍仅1个链接，原658个侧栏链接均保留。
- 未改权限表、未启用现有业务规则、未修改库存/财务数据，未部署其他站点。
- 后续正常迁移由既有 after_migrate 侧栏同步流程补齐新链接；不用新增老接口参数。
