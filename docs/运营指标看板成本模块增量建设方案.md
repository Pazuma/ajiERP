# 运营指标看板成本模块增量建设方案

日期：2026-10-16。状态：方案沉淀，待业务口径确认，尚未实施。

本文基于用户提供的看板截图、成本指标及标准成本差异分析截图，以及当前仓库代码整理。本次只新增本文档；下文代码和文件均为拟议变更，不代表已经上线。

## 1. 目标与边界

在现有“运营指标看板”增加“成本”页签，展示成本、毛利、成本结构及标准成本差异。优先新增独立分支，保留现有页面入口、五个页签、汇总接口及原有导出行为。

第一阶段不调整成本核算、库存估值、单据提交、订单成本回写和财务记账流程；不为了展示看板调用成本重算接口。现有数据不足时显示“未配置/数据不完整”，不能填零冒充真实成本，也不能用当前 BOM 价格替代历史标准成本。

标准成本差异功能分两步：先检查现有字段与数据覆盖率，具备完整标准快照及实际成本的工单才参与分析；标准快照或预算采集需另立后续增量，不在首版自动添加业务字段、钩子或回填历史数据。

## 4. 指标口径与首版可用条件

| 指标 | 拟定公式与来源 | 数据要求/限制 |
| --- | --- | --- |
| 综合毛利率 | （营业收入－营业成本）÷营业收入；按公司、过账期间汇总已生效总账，匹配财务确认的收入/成本科目集合 | 需确认科目映射、退货及冲销规则；禁止将订单金额和库存成本直接混算 |
| 分产品/分订单毛利率 | （同口径收入－对应销售成本）÷收入 | 需核实发票、交货、库存及总账关联和产品分摊；不可分摊的差额单列，不强行归产品 |
| 主营业务成本预算执行率 | 实际主营成本÷主营成本预算 | 截图名称为“主营业务成本预算完成率”；展示建议明确为预算执行率。不能替换为成本÷收入；预算来源待核实 |
| 料/工/费占比 | 各类制造成本÷同范围制造总成本 | 单独标为“生产成本结构”；不能将期间生产投入除以已结转销售成本，不能重复累计半成品与成品成本 |
| 返工报废成本占比 | （返工成本＋报废成本）÷同范围生产成本 | 需独立返工/报废成本证据；现有异常损耗字段不能未经确认直接替代 |
| 单位成本差异率 | （实际单位成本－标准单位成本）÷标准单位成本 | 同产品、同计量单位、同标准版本；只统计本期符合完工条件的工单；在制品单列，研发试制排除 |

所有金额采用公司本位币、不含税；比例以小数传输，例如 0.35 表示 35%。真实零与缺失值区分；分母为零返回不可计算及原因，不返回无穷大或伪造 0%。汇总毛利率用金额加权计算，不平均各行百分比。

财务日期按过账日期；工单差异按实际完工口径，不用计划开工日期冒充完工日期。完整完工、分批完工、期间结账边界及“完成”状态映射须实施前确认。同比、环比沿用自然月/同期规则的业务确认结果；任意日期区间的对比算法应明确标注，首版不默认沿用订单数量的等长区间对比。

### 4.1 标准成本差异公式

约定 AP=实际价格，SP=标准价格，AQ=实际用量，SQ=按实际合格产量折算的标准允许用量；AH=实际工时，SH=标准允许工时，AR/SR=实际/标准人工费率。

| 差异 | 公式 | 建议责任部门 |
| --- | --- | --- |
| 材料总差异 | AP×AQ－SP×SQ | 采购、生产 |
| 材料价格差异 | （AP－SP）×AQ | 采购 |
| 材料用量差异 | （AQ－SQ）×SP | 生产、工艺 |
| 人工费率差异 | （AR－SR）×AH | 人事、生产 |
| 人工效率差异 | （AH－SH）×SR | 生产 |
| 变动制造费用差异 | 实际变动制造费用－标准变动制造费用 | 生产、财务 |
| 固定制造费用产量差异 | 预算固定制造费用－实际产量×标准分配率 | 生产主管 |
| 固定制造费用耗费差异 | 实际固定制造费用－预算固定制造费用 | 财务、费用责任部门 |
| 单位总成本差异 | 实际单位成本－标准单位成本 | 财务、工艺 |

正差异表示超支，负差异表示节约，但负差异超过阈值也要提示标准偏高或漏记成本的可能性。变动制造费用的标准基数、固定费用标准分配率分母及差异率分母应由财务确认；不同基数的差异不能未经调节直接相加。

## 5. 调用链路与兼容设计

### 5.1 老链路保留

```text
老页签 → refresh() → operations_kpi.get_kpi_dashboard_data(filters)
       → 原有聚合 → render(data)
老导出 → operations_kpi_export.export_kpi_dashboard(filters)
       → 原有工作簿
```

### 5.2 新增成本分支

```text
点击成本页签 / 成本页签刷新 / 修改公司与日期
 → 新增 refresh_cost()：清理旧展示、生成独立请求序号
 → 新接口 operations_kpi_cost.get_cost_dashboard_data(filters)
 → 看板准入 + 财务成本权限 + 公司/单据范围校验
 → 规范化筛选 + 数据能力检查
 → 独立只读成本服务
    ├ 财务期间收入、销售成本聚合
    ├ 生产成本结构、产品明细（按权限与可用程度）
    └ 完工工单 + 历史标准快照 → 差异分析
 → 稳定数据结构（指标、口径、缺失原因、可用下钻、分页）
 → render_cost(data)，不进入原 render() 的通用兜底

成本页签导出
 → 新接口 operations_kpi_cost_export.export_cost_dashboard(filters)
 → 相同权限与只读计算服务 → 成本专用工作簿
```

成本接口失败只影响成本页签；不串行依赖老汇总接口。新页签返回老页签时恢复原渲染。公司/日期变化立即使成本缓存失效；若缓存，以用户、权限范围、公司、日期、产品/工单及口径版本为键，不跨用户复用敏感数据。首版优先不做共享服务端缓存。

现有 `render()` 在没有卡片时，会按 operations/high_tech 选择兜底指标；因此成本必须在它之前独立分支返回，不能只追加一个 tab key。现有页签点击逻辑也必须增加成本专用请求分支，不能继续只读取 `this.data`。

方法路径：`client_akivision.client_akivision.api.operations_kpi_cost.get_cost_dashboard_data`。

前端分支示意（仅方案，不可原样视为完成代码）：

```javascript
// 页签点击：cost 独立加载；其他页签仍用原数据。
this.active_tab = key;
if (key === "cost") return this.refresh_cost();
if (this.data) this.render(this.data);
else this.refresh();

// 放在 refresh()/export_excel() 原逻辑之前；其余逻辑保留。
```

## 7. 数据读取、权限与性能

财务总账建议读取已生效 GL Entry，使用选定科目树及公司本位币金额，按借贷方向处理收入、成本、退款与冲销；最终科目类型及年结转分录过滤规则需财务确认，避免汇入期末结转。产品追溯单独通过业务单据关联，禁止把同一总账金额与库存金额叠加。

生产侧核实 Work Order、Stock Entry/Detail、Job Card、BOM、预算与标准快照实际字段后再编写查询。领料、转料、退料、制造入库用途分别识别；分层生产在最终产品视角只计算根层成品成本，不能再加子工单已经结转进去的半成品成本。人工及附加费用已进入成品估值时，不再重复加入制造总成本。

成本权限默认建议财务角色及 System Manager；现有订单报表允许生产角色不代表新财务看板自动允许生产角色，需确认实际角色策略。前端可以通过服务端权限结果决定是否展示入口，但权限保护必须在新接口、导出及下钻执行。检查公司 User Permission、订单归属与科目/单据权限；原生 SQL 不会自动应用 Frappe 数据权限，必须显式限定授权范围，不能只检查角色后全表聚合。

查询按公司、过账日期/完工范围批量聚合；避免每行查 BOM/库存的 N+1。明细分页并限制 page_length；导出按同一权限和筛选取完整数据，超量时提示限制或后续增加后台任务，禁止悄悄截断。先测量真实查询计划再判断是否补索引，首版不预设数据库变更。

## 8. 受影响模块与回退

| 模块 | 影响 |
| --- | --- |
| 运营指标看板 | 新成本页签、独立加载和成本导出分支；需回归原五页签及刷新交互 |
| 财务 | 只读收入/成本及预算；新增敏感数据权限与财务口径核对 |
| 生产与库存 | 只读制造成本、完工与估值事实；不改变工单或库存状态 |
| BOM/标准成本 | 只读已有历史标准；缺失时标记不可分析，不更新标准价格 |
| 销售订单成本报表 | 保持原行为；可提供明确标为“订单累计口径”的权限下钻，不能冒充同期间对账结果 |
| 采购、回款、应收、高新合规 | 无业务逻辑变更；原页面与导出需回归 |

回退以移除 cost 页签入口和前端成本路由分支为主；若要求完全关闭访问，同时停用新接口。没有数据写入、表结构变更或历史回填，首版不需要数据回滚。

## 9. 增量实施顺序与验收

1. 口径和数据盘点：核实科目映射、实际字段、标准版本、预算、完工判定、角色与覆盖率；未满足项列清单。
2. 新建只读服务和接口，先核对公司/期间财务汇总；保留所有老接口。
3. 前端增加 cost 分支和页面，支持加载、失败重试、无数据/缺配置提示；回归异步响应竞态。
4. 接入可证明完整的生产结构及标准差异；不可用指标保持明确缺失状态。
