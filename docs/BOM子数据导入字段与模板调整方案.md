# BOM 子数据导入字段与模板调整方案

## 1. 文档目的

本文针对源文件 `development/frappe-bench/sites/aji_test.localhost/private/files/BOM表.xlsx`，沉淀其子数据导入 ERPNext 的目标表单、字段映射、表单位置和模板调整方案。

本轮只做方案和字段设计，不执行以下动作：

- 不创建或修改 `Item`、`BOM`、`BOM Item`、工程图纸等业务数据；
- 不修改 DocType、Custom Field、导入配置或前端代码；
- 不上传、不启动 Data Import 任务。

## 2. 源文件盘点

### 2.1 文件结构

| 项目 | 结果 |
| --- | --- |
| 文件 | `BOM表.xlsx` |
| 工作表 | `BOM表`，当前只有 1 个工作表 |
| 表头 | `型号`、`层级`、`物料名称`、`图纸号`、`用量` |
| 数据行 | 41 行（Excel 第 2 至 42 行） |
| 型号 | 全部为 `AKY-55R5-CGTC` |
| 层级 | 1 行为 `0`，40 行为 `1` |
| 用量 | 全部有值，主要为 `1`，另有 `2`、`3`、`4`、`8` |
| 空值 | 5 个源字段均无空值 |

第 2 行的层级 `0` 是顶层型号展示行，物料名称为 `1141`；第 3 至 42 行是 40 个直接组件。该文件是 BOM 展开结果，不是当前 ERPNext 标准导入器要求的 BOM 主表与明细分组模板。

### 2.2 源字段的业务判断

| 源列 | 判断 | 导入处理 |
| --- | --- | --- |
| 型号 | 顶层成品型号编码，重复出现在每一行 | 解析为 `BOM.item`；不得把重复值写入每一条子表行 |
| 层级 | 展开结果的计算层级 | 层级 `0` 只用于识别顶层行；直接组件固定为 `1`，不作为可编辑事实字段 |
| 物料名称 | 人工可读名称 | 通过主数据匹配 `BOM Item.item_code`；写入后的名称以 Item 主数据为准 |
| 图纸号 | 工程图纸号及版本文本，例如 `1141201118-v1` | 仅用于匹配/核对已定稿图纸，不直接覆盖 BOM Item 的只读图纸快照 |
| 用量 | 组件在直接父 BOM 中的单位用量 | 写入 `BOM Item.qty`，必须大于 0 |

源文件没有以下导入必需信息：BOM 公司的 `company`、BOM 生产数量 `quantity`、组件物料编码 `item_code`、组件单位 `uom`。这些信息不能从物料名称或图纸号直接猜测，必须在导入前补齐或由既有主数据反查确认。

## 3. 目标表单与数据落点

### 3.1 BOM 主表（生产模块：BOM）

目标表单：`BOM`，对应配置中的 `bom` / `BOM表`。

表单位置与处理方式：

| 表单区域/位置 | 系统字段 | 本次处理 | 说明 |
| --- | --- | --- | --- |
| BOM 头信息，型号 | `item` | 复用 | 从源表唯一型号 `AKY-55R5-CGTC` 匹配已存在且启用的 Item；值必须是 `Item.item_code` |
| BOM 头信息，生产数量 | `quantity` | 模板补充 | 源表没有；默认建议填 `1`，由业务确认后写入 |
| BOM 头信息，公司 | `company` | 模板补充 | 源表没有；必须选择站点已有 Company，不能用型号或客户代替 |
| BOM 头信息，单位 | `uom` | 复用系统带出 | 从顶层 Item 的库存单位带出，建议只读，不在源表手工填写 |
| BOM 头信息，启用/默认 | `is_active` / `is_default` | 模板补充默认值 | 源表没有；建议新建时分别默认 `1`、`0`，由业务确认 |
| 工程图纸 | `custom_engineering_drawing` | 可选补充 | 只有确认顶层型号存在已定稿工程图纸时才填写；不能把源表“图纸号”直接写入 Link 字段 |
| 工程图纸下方，只读图纸号/版本 | `custom_engineering_drawing_no` / `custom_engineering_drawing_revision` | 复用现有字段 | 由已定稿图纸自动快照，不允许 Excel 覆盖 |
| 标题/编号 | `name`、`custom_bom_code` | 复用系统规则 | 系统生成 `BOM-AKY-55R5-CGTC`，不在导入文件中提供可写列 |

当前代码已在 BOM 的 `item` 后增加定稿图纸字段，并在详情配置中将 BOM 编码、型号、数量、启用、默认等放在列表/头信息区域。本方案不重复新增同名业务字段。

### 3.2 BOM 明细子表（BOM 表单内的“物料明细”）

目标位置：`BOM` 表单的 `items` 子表，子表 DocType 为 `BOM Item`。源表第 3 至 42 行分别转换为 40 条明细。

建议的表单列顺序：

1. 序号 `idx`（系统生成）；
2. 物料编码 `item_code`；
3. 物料名称 `item_name`；
4. 图纸号 `custom_engineering_drawing_no`；
5. 图纸版本 `custom_engineering_drawing_revision`；
6. 用量 `qty`；
7. 单位 `uom`；
8. 子 BOM `bom_no`；
9. 备注/说明（如业务确认需要）。

字段映射和修改如下：

| 表单位置 | 系统字段 | 源列/模板列 | 状态 | 修改与规则 |
| --- | --- | --- | --- | --- |
| 物料明细第 2 列 | `item_code` | 新增模板列“物料编码” | 已有字段，必须补充数据 | 不能用“物料名称”或“图纸号”代替；须匹配已存在且启用的 Item |
| 物料明细第 3 列 | `item_name` | 源列“物料名称” | 已有字段 | 仅人工核对；保存时以 `item_code` 对应 Item 主数据为准，建议只读/不覆盖 |
| 物料明细第 4 列 | `custom_engineering_drawing_no` | 源列“图纸号” | 已有只读字段 | 由组件 Item 的已定稿图纸自动快照；模板列仅作为校验值，不写入业务字段 |
| 物料明细第 5 列 | `custom_engineering_drawing_revision` | 从“图纸号”解析/主数据取得 | 已有只读字段 | 不允许 Excel 直接覆盖；图纸号与版本必须和组件当前定稿图纸一致 |
| 物料明细第 6 列 | `qty` | 源列“用量” | 已有字段 | 写入 40 条直接组件用量；必须为大于 0 的数字 |
| 物料明细第 7 列 | `uom` | 新增模板列“单位” | 已有字段，必须补充数据 | 优先从组件 Item 的 `stock_uom` 带出；必须是已存在的 UOM |
| 物料明细第 8 列 | `bom_no` | 源表没有 | 已有字段，留空 | 当前文件全为直接组件；只有半成品继续展开时才填写已提交的子 BOM |
| 物料明细隐藏校验字段 | `custom_import_level` | 源列“层级”转换 | 已有自定义字段 | 直接组件统一为 `1`；源表层级 `0` 行不写入明细，仅用于识别 BOM 头 |
| 物料明细图纸 Link | `custom_engineering_drawing` | 从 Item/图纸主数据带出 | 已有只读字段 | 不增加 Excel 可写列，由系统根据组件 Item 的有效图纸生成 |

不建议新增一个可写的“图纸号”或“层级”业务字段。图纸号属于快照，层级属于 BOM 展开计算结果；如需要保留原始值，应作为导入预检结果或错误报告中的临时列，不落库到 `BOM Item`。

### 3.3 BOM 展开结构（只读视图）

目标位置：BOM 详情中的“BOM 展开结构”区域，或 BOM 列表的只读导出，不作为导入表单。

现有展开接口已按 `bom_no` 递归生成以下结果：型号、层级、物料编码、物料名称、图纸号、图纸版本、用量、单位、父级 BOM。源文件的五列可在此区域呈现，但不应反向作为业务事实直接导入。

本文件的层级 `0` 行应进入展开视图的顶层行；40 条层级 `1` 行进入顶层 BOM 的直接组件。由于当前文件没有子 BOM 关系，导入后展开结果预期只有层级 `0` 和层级 `1`。

## 4. 导入模板调整

### 4.1 当前配置与缺口

当前 `client_akivision/config/excel_import_tables.json` 中 `bom` 配置已有以下字段：

- BOM 主表：`item`、`company`、`quantity`、`custom_engineering_drawing`、`is_active`、`is_default`；
- 明细子表：`item_code`、`item_name`、`custom_import_level`、`qty`、`uom`、`bom_no`。

配置已经覆盖大部分标准可写字段，但与本源文件相比仍缺少或需要明确处理：

1. 模板必须出现“公司”和“生产数量”，否则 BOM 主表无法保存；
2. 模板必须出现“物料编码”和“单位”，否则 BOM Item 无法保存；
3. 源列“图纸号”不能映射到只读 `custom_engineering_drawing_no`；需要增加“导入校验列”语义；
4. 源列“层级”不能作为普通可写字段；层级 `0` 应转换为 BOM 头，层级 `1` 才能作为直接明细；
5. 当前源表将型号重复在每一行，标准 Data Import 需要按父行/子行分组，不能把 41 行都当作独立 BOM 头。

### 4.2 推荐模板结构

推荐下载模板最终包含三个工作表：

| 工作表 | 是否导入 | 用途 |
| --- | --- | --- |
| `BOM表` | 是 | 一行一张 BOM，承载型号、公司、生产数量、启用、默认、定稿图纸 |
| `BOM明细` | 是 | 一行一个直接组件，承载父型号、物料编码、物料名称核对值、图纸号核对值、层级校验值、用量、单位、子 BOM |
| `BOM展开预览` | 否，只读导出 | 展示系统根据真实 BOM 关系计算出的层级结构 |

#### `BOM表` 建议列

| 模板列 | 系统字段 | 必填 | 备注 |
| --- | --- | ---: | --- |
| 型号编码 | `item` | 是 | 已存在的 Item 编码 |
| 公司 | `company` | 是 | 已存在的 Company |
| 生产数量 | `quantity` | 是 | 当前源数据建议为 `1`，须业务确认 |
| 单位 | `uom` | 否 | 从顶层 Item 带出，只读或自动填充 |
| 定稿图纸 | `custom_engineering_drawing` | 否 | 已定稿 Engineering Drawing 的名称/编号 |
| 启用 | `is_active` | 否 | 默认 `1` |
| 默认 BOM | `is_default` | 否 | 默认 `0` |

#### `BOM明细` 建议列

| 模板列 | 系统字段/用途 | 必填 | 备注 |
| --- | --- | ---: | --- |
| 父型号编码 | 分组键，解析到 `BOM.item` | 是 | 不新增为 BOM Item 业务字段；用于关联 `BOM表` |
| 物料编码 | `items.item_code` | 是 | 真实 Item 编码 |
| 物料名称 | `items.item_name` | 否 | 人工核对值，系统以 Item 主数据为准 |
| 图纸号 | 导入校验值 | 否 | 与组件 Item 当前定稿图纸核对，不写入快照字段 |
| 层级 | 导入校验值/`custom_import_level` | 是 | 直接组件固定为 `1`；不接受 `0` 作为子行 |
| 用量 | `items.qty` | 是 | 大于 0 |
| 单位 | `items.uom` | 是 | 已存在 UOM，通常取 Item.stock_uom |
| 子 BOM 编码 | `items.bom_no` | 否 | 半成品才填写；必须防循环 |

### 4.3 当前源文件的转换结果

导入前应将源文件转换为以下逻辑数据，而不是原样上传：

- `BOM表`：新增 1 行，型号 `AKY-55R5-CGTC`；公司和数量需要人工补齐；默认建议数量 `1`；
- `BOM明细`：取源文件第 3 至 42 行，共 40 行；保留用量；将物料名称和图纸号作为匹配/校验信息；补齐物料编码和单位；层级统一为 `1`；子 BOM 为空；
- 源文件第 2 行（层级 `0`）不导入 `BOM Item`，只用于确认顶层型号和顶层图纸号；
- “图纸号”不能直接当作 `item_code`。应先按 Item 编码、物料名称、当前有效工程图纸三者进行匹配，匹配不到的行必须进入人工待处理清单。

## 5. 需要新增或调整的项目清单

### 5.1 需要新增到模板/导入协议的列

| 项目 | 放置位置 | 类型 | 是否落库 | 目的 |
| --- | --- | --- | --- | --- |
| 公司 | `BOM表` | Link: Company | 是 | 满足 BOM 主表必填字段 |
| 生产数量 | `BOM表` | Float | 是 | 满足 BOM 主表必填字段；当前建议为 1 |
| 父型号编码 | `BOM明细` | Link/分组键 | 否，作为导入协议字段 | 将子数据关联到对应 BOM，避免依赖 Excel 行号 |
| 物料编码 | `BOM明细` | Link: Item | 是 | 满足 BOM Item 必填字段 |
| 单位 | `BOM明细` | Link: UOM | 是 | 满足 BOM Item 必填字段 |
| 图纸号校验值 | `BOM明细` | Data | 否 | 核对图纸快照，不允许覆盖只读字段 |
| 层级校验值 | `BOM明细` | Int | 否/或写入隐藏校验字段 | 校验直接组件为 1，禁止将顶层 0 行写入子表 |

### 5.2 不应新增为可写业务字段的项目

- BOM 编码：由系统按 `BOM-{型号编码}` 生成；
- 型号名称：由 `Item.item_name` 带出；
- BOM/组件图纸号和图纸版本：由已定稿图纸自动快照；
- 展开层级：由 `bom_no` 递归计算；
- 成本、状态、库存和累计用量：由系统计算或单据状态生成。

### 5.3 表单位置调整建议

1. `BOM` 头部：保持“BOM 编码、型号、型号名称、公司、生产数量、单位、启用、默认”顺序；
2. `BOM` 工程图纸区域：放置定稿图纸、只读图纸号、图纸版本；
3. `BOM.items` 子表：将物料编码、物料名称、图纸号、图纸版本、用量、单位放在首屏，子 BOM 和其他标准字段放在后续列；
4. `BOM` 详情增加或保留只读“BOM 展开结构”区域，展示源文件相同的型号/层级/物料名称/图纸号/用量，但数据来源必须是已保存 BOM；
5. 导入字段选择界面：将 `item`、`company`、`quantity`、`items.item_code`、`items.qty`、`items.uom` 标为默认且必选；将物料名称、图纸号、层级标注为核对/校验列；
6. 只读字段不应出现在可写导入字段清单中，避免用户误以为可以用 Excel 覆盖快照。

## 6. 导入前置校验与阻断条件

导入执行前必须形成校验报告，至少包括工作表、行号、字段、原值、处理结果：

1. `AKY-55R5-CGTC` 是否已存在且启用的 Item；
2. 40 个组件是否能唯一匹配 Item 编码；仅名称相同或仅图纸号相同不能自动确认；
3. 组件 Item 是否存在有效库存单位，且单位已存在于 UOM；
4. 组件图纸号是否与 Item 当前已定稿图纸的图纸号/版本一致；
5. Company 是否已确认；BOM 生产数量是否大于 0；
6. 是否已经存在同型号、同公司的 BOM；已有 BOM 不得静默覆盖，必须转为更新/修订流程；
7. 是否存在重复组件、重复行号或无效数量；
8. 源表层级 `0` 行是否已排除出 BOM Item，层级 `1` 行是否全部保留；
9. 子 BOM 若后续补填，是否存在、已提交、顶层物料与组件一致，且没有循环引用。

任何关键校验失败时，整张 BOM 不启动写入。尤其不能用“物料名称”代替缺失的物料编码，也不能把“图纸号”直接写入只读快照字段。

## 8. 实施顺序（本轮不执行）

1. 先确认上述业务项并完成 Item、UOM、Company、Engineering Drawing 主数据核对；
2. 实现或确认 `BOM表`/`BOM明细` 模板及父子分组解析；

4. 用转换后的副本做预览和逐行校验，不启动正式导入；
5. 业务确认预览结果后，再单独安排正式导入，并保留错误行和导入日志。

## 9. 原五列表直接导入方案

如果业务要求保留当前文件的五列，不增加 Excel 列、不拆分工作表，可以增加“BOM 展开表直接导入”模式。该模式不能使用标准 Data Import 的逐列写入逻辑，而应在 BOM 导入入口先解析展开表，再调用标准 BOM 保存校验。

### 9.1 保持不变的源文件格式

源文件仍只需要以下五列，列名保持不变：

```text
型号 | 层级 | 物料名称 | 图纸号 | 用量
```

解析规则：

1. 文件必须只有一个 `BOM表` 工作表；
2. 必须且只能有一个层级 `0` 行，该行识别为 BOM 顶层；
3. 层级 `1` 行识别为当前 BOM 的直接组件；
4. 当前文件中重复的“型号”只作为分组信息，不重复创建 BOM；
5. 层级大于 `1` 的行必须阻断并提示拆分子 BOM；
6. 空值、重复图纸号、用量小于等于 0 必须在预览阶段报错。

### 9.2 自动字段推导

导入器在预览阶段自动生成标准 BOM 所需字段：

| 原表信息 | 自动生成/匹配字段 | 处理规则 |
| --- | --- | --- |
| 层级 0 行的“型号” | `BOM.item` | 按 `Item.item_code` 精确匹配 |
| 层级 0 行的“用量” | `BOM.quantity` | 当前文件建议固定为 `1`；不采用顶层展示行的用量作为组件用量 |
| 系统默认公司或导入窗口选择 | `BOM.company` | 必须由用户确认；没有默认公司时禁止启动导入 |
| 层级 0 行 | `BOM.is_active` / `BOM.is_default` | 默认 `1` / `0`，允许在导入窗口调整 |
| 层级 1 行的“图纸号” | `BOM Item.item_code` 的候选值 | 优先按 Item 编码精确匹配；匹配失败不得直接创建物料 |
| 层级 1 行的“物料名称” | `BOM Item.item_name` 核对值 | 与匹配到的 Item 名称核对，不覆盖主数据 |
| 层级 1 行的“用量” | `BOM Item.qty` | 原样写入，必须大于 0 |
| 匹配到的 Item.stock_uom | `BOM Item.uom` | 自动带出，必须是有效 UOM |
| 层级 1 行的“层级” | `custom_import_level` | 自动写入 `1`；不接受层级 0 作为子表行 |
| 匹配到的 Item 有效图纸 | 图纸快照字段 | 校验原表“图纸号”，由系统生成只读快照 |

对于当前文件，预期转换为：1 个 BOM 头 + 40 条 BOM Item 明细。`图纸号`只有在站点中确实是对应 Item 编码时才能自动作为 `item_code`；否则必须在预览中提供“选择匹配物料”步骤，不能按名称模糊创建。

### 9.3 导入界面调整

在 BOM 列表的导入窗口增加导入模式：

- `标准 BOM 模板导入`：使用 `BOM表` + `BOM明细` 两个工作表；
- `BOM 展开表直接导入`：使用当前五列表，自动完成上述解析。

选择“直接导入”后，预览页必须显示：

1. 识别出的 BOM 型号、公司、生产数量和拟生成的 BOM 编码；
2. 40 条组件的物料编码匹配结果、名称核对结果、单位、用量；
3. 图纸号是否与 Item 当前有效图纸一致；
4. 自动补齐了哪些字段；
5. 未匹配、重复或需要人工确认的行。

存在任何阻断错误时，禁用“开始导入”，不能出现“部分写入后再补数据”的状态。

### 9.4 后端实现边界

建议新增独立的 BOM 展开表解析服务/接口，不修改普通 `Item`、销售订单等表单的导入行为：

1. 读取上传文件并严格校验五列表头；
2. 找到层级 0 顶层行，解析唯一 `BOM.item`；
3. 逐行按图纸号、物料编码、物料名称进行安全匹配；
4. 生成内存中的 BOM 主表和 `items` 子表对象；
5. 执行公司、Item、UOM、图纸、数量、重复 BOM、层级和循环引用校验；
6. 预览无错误后，交给标准 BOM 保存/提交逻辑；
7. 失败时整批回滚，并记录原 Excel 行号和字段值。

该服务不能自动新建缺失 Item、UOM、Company 或工程图纸。缺失主数据应先导入对应主数据表单，再重新进行 BOM 预览。

### 9.5 当前文件的直接导入前提

对 `BOM表.xlsx` 执行直接导入前，必须确认：

- `AKY-55R5-CGTC` 已存在且启用，且确实是顶层 Item 编码；
- 40 个“图纸号”能唯一匹配现有 Item 编码，或能通过人工逐行确认匹配；
- 每个组件 Item 有有效库存单位；
- 导入公司已选择；
- 顶层 BOM 数量确认采用 `1`；
- 顶层型号没有已存在的冲突 BOM，或已明确走更新/修订流程；
- 所有组件图纸号与当前有效定稿图纸一致。

只要有一条组件无法安全匹配，直接导入就应停在预览阶段，而不是将“物料名称”或“图纸号”盲写到错误字段。

## 10. 结论

本 Excel 可以通过新增“BOM 展开表直接导入”模式原样上传：系统自动识别 1 个 BOM 头和 40 条直接组件，补齐公司、数量、物料编码和单位，并在预览阶段完成主数据与图纸校验。若不实现该专用解析模式，则仍必须先转换为 `BOM表` + `BOM明细` 模板，不能把当前五列表直接交给标准 Data Import。
