# 物料折旧简化实施记录

日期：2026-10-23；验证站点：`aki_test.localhost`。

## 已实现效果

物料的折旧明细只显示四类信息，其中周期拆为数量、单位两个控件：

```text
折旧物料表
周期数量 | 周期单位 | 每周期减少（%） | 原始单价 | 最后使用时间
    1    |    月    |        5        |  100.00  | 系统统计、只读

展开行 → 更多设置（默认收起）
启用自动评估、仓库、起算日期、免减值月数、累计上限
库存数量、评估结果、历史使用日期、状态、备注

更多设置（历史兼容）（默认收起）
保留父物料旧开关、规则说明、上限、恢复保护期、允许转回

库存 → 报表 → 物料折旧汇总
公司 [选择]  仓库 [选择]  物料 [选择]  库存范围 [仅有库存]
物料 | 周期 | 每周期减少（%） | 原始单价 | 最后使用时间
```

汇总中悬停物料可查看物料名称及仓库，点击物料进入原设置。仍按物料、仓库分别统计，不合并不同仓库规则。无有效使用记录不虚构日期，汇总显示“暂无有效使用记录”。

## 计算及兼容

- 周期单位可选年、月、日；数量必须至少1。每周期减少按原始单价百分比累加，不复利，受原累计上限限制。
- 1年按12个完整日历月计算；月末、闰年沿用原日历边界。日周期按免减值期结束后的完整天数计算。
- 免减值期仍按月填写，放在更多设置，不改变历史含义。
- 保留技术字段 `period_months` 存储周期数量，新增 `period_unit`；旧记录无单位时按月解释。旧月规则不重写、不强制重新启用。
- `last_usage_time` 为新增只读虚拟字段。通过只读接口获取有效库存出库时间，不把旧手工日期当成系统使用时间，不因刷新弄脏物料。
- 系统使用来源沿用汇总已有口径：已提交非退货销售出库、更新库存销售发票、制造/制造消耗的有效负向库存流水。排除调拨、草稿、取消、未来记录等。
- 最后使用时间按当前已保存物料与规则仓库统计；新增规则或新仓库保存后统计。不因使用而自动重置折旧起算日。
- 保留旧日期、库存与测算字段数据，明细移入更多设置。父物料旧字段仍保留，不替代子表的启用规则。
- 保留报表原API参数及返回明细，旧列仅标记隐藏；默认Excel/CSV导出跟随五列简表。原闲置天数参数后端仍支持，页面不再展示。
- 无自动财务计提，无库存估值、采购价、销售价联动写入。

## 文件与调用链路

| 文件 | 改动 |
| --- | --- |
| `client_akivision/client_akivision/doctype/inventory_impairment_item/inventory_impairment_item.json` | 精简列表、增加周期单位与虚拟使用时间、折叠更多设置 |
| `client_akivision/public/js/item_form_layout.js` | 历史设置收纳、异步读取使用时间、防旧请求覆盖、不触发物料修改 |
| `client_akivision/utils/inventory_impairment.py` | 原计算器新增年/日分支；新增 `get_item_usage_times`，保留原保存与调度接口 |
| `client_akivision/utils/inventory_impairment_summary.py` | 读取单位、增加周期说明与完整时间、五列简表、旧细节列隐藏 |
| `client_akivision/client_akivision/report/物料折旧汇总/物料折旧汇总.js` | 简化筛选、空使用记录说明、物料仓库提示 |
| `client_akivision/tests/test_inventory_impairment.py` | 日/年边界、闰年、无单位旧月规则兼容 |
| `client_akivision/utils/test_inventory_impairment_summary.py` | 五列与默认导出、使用时间权限和只读验证 |

保存：Item.validate → assess_item → calculate_assessment（按单位分支）→ 原子表快照。

每日：scheduled_assess_items → 原保存计算器 → 更新原有启用规则评估快照。

打开物料：Item.refresh → get_item_usage_times → 物料读取权限 + 公司/仓库权限过滤 → get_last_effective_usage → 虚拟字段显示。无基础权限返回空时间映射；无物料读取权限拒绝访问。

打开汇总/导出：标准报表 → get_summary → 现有权限过滤及候选规则 → 同一计算器 → 有效使用统计 → 五列显示/默认导出，旧明细留在返回结果中。
