# BOM 字段、编号与模板导入设计沉淀

## 1. 目标与边界

本文根据提供的 `BOM表` 截图，定义 ERP 中 BOM 的编号、详情页面、明细字段和 Excel 模板导入规则。

目标效果是：

- BOM 的业务编码固定为 `BOM-型号编码`，例如型号编码为 `AKY-55R5-CGTC` 时，BOM 编码为 `BOM-AKY-55R5-CGTC`；
- 进入 BOM 详情后，至少能维护或查看图片中的“型号、层级、物料名称、图纸号、用量”；
- BOM 明细仍使用 ERPNext 标准 `BOM Item`，保留物料编码、单位、损耗、替代料、子 BOM 等标准能力；
- Excel 导入向导的 `BOM表` 模板同时提供 BOM 头和物料明细所需列，并能校验主数据、父子关系和数量；
- 不把图片中的 Excel 表另建为一份脱离 BOM、物料和工程图纸的事实数据。

本设计不改变物料、工程图纸、生产工单、库存和采购建议的事实来源。BOM 被提交后仍按 ERPNext 的单据状态和权限控制使用。

## 2. 图片字段的业务理解

截图中每一行表示一个型号 BOM 中的一个展开节点，列为：

| 图片列 | 业务含义 | 示例 |
| --- | --- | --- |
| 型号 | 顶层成品的型号编码；同一张 BOM 的明细行重复显示同一个值 | `AKY-55R5-CGTC` |
| 层级 | 该节点相对顶层 BOM 的层数；顶层成品为 `0`，其直接用料为 `1`，下级子 BOM 的物料为 `2` 及以后 | `0`、`1`、`2` |
| 物料名称 | 顶层成品或组件物料的名称 | `P E板270x180x0.08` |
| 图纸号 | 该物料当前定稿图纸的图号和版本 | `1141201118-v1` |
| 用量 | 在其直接父级 BOM 中的单位用量 | `1`、`2`、`8` |

截图第一条层级 `0` 的记录是顶层型号本身，用于让导出文件可独立识别 BOM；其余记录是组件。黄色底色属于原 Excel 的人工标记，不是 BOM 的业务字段，不应导入为状态、分类或版本依据。

## 3. 数据模型与字段映射

### 3.1 BOM 头信息

一个 `BOM` 代表一个待生产型号的一套直接用料结构。字段定义如下：

| 页面标签 | 系统字段 | 类型/来源 | 填写规则 |
| --- | --- | --- | --- |
| BOM 编码 | `BOM.name` | 系统编号 | 自动生成，格式 `BOM-{型号编码}`，只读。 |
| 型号编码 | `BOM.item` | Link / `Item` | 必填。必须选择顶层成品物料，值为 `Item.item_code`。 |
| 型号名称 | `BOM.item_name` | 从 `Item.item_name` 带出 | 只读。用于帮助识别，不代替型号编码。 |
| 生产数量 | `BOM.quantity` | Float | 必填，默认 `1`；所有明细用量以该产出数量为基准。 |
| 单位 | `BOM.uom` | 从顶层物料带出 | 只读。 |
| 公司 | `BOM.company` | Link / `Company` | 必填。 |
| 定稿图纸 | `BOM.custom_engineering_drawing` | Link / `Engineering Drawing` | 可选；选择后必须是“已定稿”图纸。 |
| 图纸号 | `BOM.custom_engineering_drawing_no` | 从定稿图纸快照 | 只读。 |
| 图纸版本 | `BOM.custom_engineering_drawing_revision` | 从定稿图纸快照 | 只读。 |
| 启用 | `BOM.is_active` | Check | 启用的 BOM 才可被后续业务选择。 |
| 默认 BOM | `BOM.is_default` | Check | 同一型号、同一公司同一时点最多一张有效默认 BOM。 |
| 状态 | `BOM.docstatus` | 系统状态 | 草稿、已提交、已取消；不在 Excel 中手工写入。 |

“型号”在图片中是顶层产品编码，不是可以任意填写的文本。详情和导入都必须通过 `BOM.item` 关联既有物料，物料编码是唯一匹配键，物料名称只做展示。

### 3.2 BOM 直接物料明细

详情页的“物料明细”子表使用 `BOM.items`（`BOM Item`）。建议按以下顺序展示：

| 顺序 | 页面标签 | 系统字段 | 类型/来源 | 规则 |
| ---: | --- | --- | --- | --- |
| 1 | 序号 | `idx` | 系统行号 | 明细排序依据。 |
| 2 | 物料编码 | `item_code` | Link / `Item` | 必填，必须是已启用的物料。 |
| 3 | 物料名称 | `item_name` | 从物料带出 | 只读。对应图片“物料名称”。 |
| 4 | 图纸号 | `custom_engineering_drawing_no` | 从组件物料的定稿图纸快照 | 只读。对应图片“图纸号”。 |
| 5 | 图纸版本 | `custom_engineering_drawing_revision` | 从组件物料的定稿图纸快照 | 只读，显示在图纸号旁，避免图号相同但版本不明。 |
| 6 | 用量 | `qty` | Float | 必填且大于零；对应图片“用量”，是每个 `BOM.quantity` 所需数量。 |
| 7 | 单位 | `uom` | Link / `UOM` | 必填；与库存单位换算沿用标准逻辑。 |
| 8 | 损耗/损耗率 | 站点确认后的 BOM 明细字段 | Float | 可选；当前标准 `BOM Item` 不以固定“损耗率”字段承载，若业务确有需求应单独定义字段，且不混入用量。 |
| 9 | 子 BOM | `bom_no` | Link / `BOM` | 仅半成品需要继续展开时填写。 |
| 10 | 备注 | `description` 或明确的自定义备注字段 | Text | 可选，记录工艺、替代限制等说明。 |

现有图纸校验会在保存 BOM 时，将组件物料的已定稿图纸、图纸号和版本快照到明细行；组件没有定稿图纸时，图纸号允许为空。选择或关联未定稿图纸时必须阻止保存，不能从 Excel 的图纸号文本绕过图纸定稿校验。

### 3.3 层级字段的正确位置

图片的“层级”不是一张普通 BOM 的手工明细字段，而是整个产品结构展开后的计算结果：

```text
顶层 BOM（型号 A）                         层级 0
├── 原材料 X                                 层级 1
└── 半成品 B（其子 BOM 为 BOM-B）             层级 1
    ├── 原材料 Y                             层级 2
    └── 原材料 Z                             层级 2
```

因此：

1. BOM 详情的 `items` 只录入当前 BOM 的直接组件；直接组件在该详情中固定视为层级 `1`，不提供可编辑的“层级”输入框。
2. 需要图中效果时，提供“BOM 展开结构”只读视图或导出表。它从顶层 BOM 递归读取 `bom_no`，计算 `0/1/2/...`。
3. Excel 导入的事实模板也只导入直接组件。若上传文件包含多层结构，必须明确父级型号/父级 BOM，导入器据此拆分为多张 BOM，而不是把层级 `2` 物料直接塞进顶层 BOM。
4. 物料被多个半成品共用时，展开视图允许出现多次，因为其父级不同；标准 BOM 明细不能以“物料编码去重”而丢失该结构。

## 4. 编码规则与版本边界

### 4.1 编码规则

BOM 编码定义为：

```text
BOM-{型号编码}
```

例如：

| 型号编码（`BOM.item` / `Item.item_code`） | BOM 编码（`BOM.name`） |
| --- | --- |
| `AKY-55R5-CGTC` | `BOM-AKY-55R5-CGTC` |
| `AKY-101` | `BOM-AKY-101` |

生成规则：

1. 保存新 BOM 前，系统取已选顶层物料的 `item_code`，生成 `BOM-{item_code}`。
2. 用户不能手工编辑 BOM 编码，也不能用物料名称、外部型号、机种或图纸号替代型号编码。
3. 型号编码中原有的连字符保留，不转换为流水号；编码必须在 `BOM` 中唯一。
4. Excel 中的“型号”列只允许填写已存在的型号编码；导入时系统按同一规则计算 BOM 编码，不接受另一列覆盖该编码。

### 4.2 与 ERPNext 修订机制的约束

ERPNext 已提交 BOM 在变更时通常会走“取消后修订”，新单据名称会自动产生修订后缀。该标准行为与“每个型号始终只有一个 `BOM-型号编码` 文档名”存在冲突：数据库中已存在或已取消的同名 BOM 不能再次创建。

本需求的实施前必须选定以下一种规则；在规则确定前，不应直接改写标准命名：

| 选项 | 编码表现 | 适用与影响 |
| --- | --- | --- |
| A. 单一 BOM 模式 | 仅允许一张 `BOM-型号编码`；提交后不通过新增 BOM 修订 | 最严格满足用户指定编码。工程变更需在提交前完成，或走受控的替换/历史归档流程。 |
| B. 固定业务编码 + 系统修订名 | 页面显示业务编码 `BOM-型号编码`，修订文档实际名称按 `BOM-型号编码-1`、`-2` 等生成 | 保留标准追溯能力，但严格意义上 `BOM.name` 不再始终等于业务编码。 |

若没有额外确认，本文建议采用 **B**：首版名称为 `BOM-型号编码`，后续修订追加标准后缀，并把首段作为“BOM 业务编码”显示和导出。原因是生产、采购、工程图纸和历史工单必须能够反查变更前的 BOM，不能以覆盖或删除历史 BOM 的方式保持同一名称。

无论采用哪种选项，同一型号同一公司同一时点只能有一张“启用且默认”的 BOM。创建或导入重复型号时，应给出已存在 BOM 编码和状态，要求用户进入原单维护或按修订流程处理，不能静默覆盖明细。

## 5. 详情页呈现

进入 BOM 后，页面至少应按以下区域组织：

1. **标题和基本信息**：BOM 编码、型号编码、型号名称、公司、生产数量、单位、状态、启用、默认 BOM。
2. **工程图纸**：定稿图纸链接、图纸号、图纸版本。图纸号与版本只读且可追溯来源图纸。
3. **物料明细**：按第 3.2 节的列顺序展示，首屏保留物料编码、物料名称、图纸号、用量、单位；非高频标准列可收纳在列设置中。
4. **展开结构**：只读展示顶层型号、层级、物料编码、物料名称、图纸号、图纸版本、单位用量、累计用量、父级 BOM。该区域对齐截图字段并支持导出。
5. **成本与生产信息**：保留 ERPNext 标准成本、工序、仓库、项目、质量和关联单据区域，不能因页面简化而删除。

列表页建议显示：`BOM 编码`、`型号编码`、`型号名称`、`图纸号`、`图纸版本`、`启用`、`默认 BOM`、`状态`、`修改时间`。用户点击 BOM 编码进入详情。

## 6. Excel 模板与导入规则

### 6.1 模板结构

`BOM表` 模板采用主表与明细表两个工作表，不能把一套多行 BOM 压缩在一个单元格中：

| 工作表 | 用途 | 一行代表 |
| --- | --- | --- |
| `BOM表` | BOM 头 | 一张型号 BOM。 |
| `BOM明细` | BOM 直接组件 | 某张 BOM 的一条直接用料。 |
| `BOM展开预览` | 可选只读导出 | 顶层型号的一条展开节点；不作为导入工作表。 |

### 6.2 `BOM表` 字段

| 模板列 | 系统字段 | 必填 | 规则 |
| --- | --- | ---: | --- |
| 型号编码 | `BOM.item` | 是 | 填 `Item.item_code`，必须已存在且启用。 |
| 生产数量 | `BOM.quantity` | 是 | 大于 `0`，通常填 `1`。 |
| 公司 | `BOM.company` | 是 | 必须是已存在公司。 |
| 定稿图纸 | `BOM.custom_engineering_drawing` | 否 | 填工程图纸编号；图纸必须已定稿并与型号匹配。 |
| 启用 | `BOM.is_active` | 否 | 空值按默认启用；只接受 `0/1` 或明确的真/假格式。 |
| 默认 BOM | `BOM.is_default` | 否 | 空值按默认否；同型号仅允许一张为真。 |
| 备注 | BOM 备注字段 | 否 | 仅业务说明，不承载图纸号、型号或层级。 |

`BOM 编码`、`型号名称`、`图纸号`、`图纸版本`、状态、成本均不作为可写导入列：它们分别由命名规则、主数据/图纸快照、单据状态和系统成本计算生成。

### 6.3 `BOM明细` 字段

| 模板列 | 系统字段 | 必填 | 规则 |
| --- | --- | ---: | --- |
| 父型号编码 | 解析到 `BOM.item` | 是 | 与 `BOM表.型号编码` 匹配，用于归属明细；不得靠 Excel 行号关联。 |
| 行号 | `BOM Item.idx` | 否 | 不填时按导入行顺序生成；同一父型号内必须唯一。 |
| 物料编码 | `BOM Item.item_code` | 是 | 必须是已存在且启用的物料。 |
| 物料名称 | `BOM Item.item_name` | 否 | 只用于人工核对；导入后以物料主数据为准。 |
| 用量 | `BOM Item.qty` | 是 | 大于 `0`。 |
| 单位 | `BOM Item.uom` | 是 | 必须是物料允许使用的单位。 |
| 子 BOM 编码 | `BOM Item.bom_no` | 否 | 填对应 BOM 编码；必须存在、已提交且顶层物料与组件物料一致。 |
| 图纸号 | 校验/展示列 | 否 | 只用于与物料当前定稿图纸核对，不写入快照字段；不一致即报错。 |
| 层级 | 预览校验列 | 否 | 默认不接受作为事实输入；仅多层模板导入模式下用于与父级关系交叉校验。 |
| 备注 | 明细备注字段 | 否 | 记录工艺说明。 |

### 6.4 多层结构导入

支持图片中的多层结构时，导入文件必须将每个半成品建立为独立 `BOM表` 记录，并在其上级 `BOM明细.子 BOM 编码` 中关联。例如：

```text
BOM表：型号 A、型号 B
BOM明细：父型号 A -> 原材料 X
BOM明细：父型号 A -> 组件 B，子 BOM 编码 BOM-B
BOM明细：父型号 B -> 原材料 Y
```

“层级”由导入完成后根据 `BOM Item.bom_no` 计算，不能只凭某行填写 `2` 就推断其父级。导入前必须检查：父型号存在、子 BOM 的顶层物料等于该组件物料、没有循环引用（A -> B -> A）、用量和单位有效。

### 6.5 导入处理原则

1. 主数据前置：所有型号/组件物料、单位、公司、工程图纸必须先创建，BOM 模板不负责新建这些主数据。
2. 先校验后写入：先汇总检查必填、Link、重复 BOM、图纸状态、子 BOM 关系和数量；任何关键错误均阻止该导入批次提交。
3. 新建与更新分开：新建模式不能覆盖已有 BOM；更新必须指定已有 BOM 编码，并仅允许草稿 BOM 更新。已提交 BOM 使用修订流程。
4. 一个父型号至少一条有效直接组件；没有组件的 BOM 不允许导入提交。
5. 导入成功后，由标准 BOM 校验、图纸快照和成本计算生成系统字段；不能通过 Excel 强制写入只读快照、状态或成本。

## 7. 现有配置差距与实施范围

当前系统已经具备以下基础：

- 标准 `BOM` 与 `BOM Item`，并已开放 `BOM表` 作为可导入业务表；
- `BOM.item` 已显示为“型号”，`BOM Item.item_name` 已显示为“物料名称”，`BOM Item.qty` 已显示为“用量”；
- BOM 头和 BOM 明细已具备工程图纸、图纸号、图纸版本字段，且保存时会校验定稿状态并生成组件图纸快照；
- 现有默认导入字段仅包括 BOM 头的型号、生产数量、启用、默认 BOM，以及明细的物料编码、用量、单位。

为实现本文目标，后续实施需要调整：

| 范围 | 所需变化 |
| --- | --- |
| BOM 命名 | 实现 `BOM-型号编码` 的生成与重复校验，并落实第 4.2 节的修订选项。 |
| 详情布局 | 将 BOM 编码、型号、图纸信息和明细高频列按第 5 节排序；新增只读展开结构入口/视图。 |
| 导入配置 | 扩展 `BOM表` 默认字段，增加公司、定稿图纸和明细父级关系/子 BOM；模板以双工作表表达头明细。 |
| 导入校验 | 增加图纸定稿、型号-图纸一致性、单位、用量、重复 BOM、子 BOM 与循环引用校验。 |
| 展示配置 | 更新列表、详情、子表和展开导出字段，使模板中的每一列都有明确的查看位置。 |
| 历史数据 | 为既有 BOM 制定一次性映射策略；不能盲目改写已被工单、采购、库存或图纸引用的 `BOM.name`。 |

## 8. 验收标准

1. 新建型号 `AKY-55R5-CGTC` 的首张 BOM 后，BOM 编码显示为 `BOM-AKY-55R5-CGTC`，且用户无法手工篡改。
2. 进入 BOM 详情可清楚看到型号编码、型号名称、图纸号、图纸版本、生产数量、单位、状态和物料明细。
3. 明细首屏至少显示物料编码、物料名称、图纸号、用量、单位；组件图纸从已定稿物料图纸自动快照，未定稿图纸不能保存。
4. BOM 展开视图或导出与截图一致，包含型号、层级、物料名称、图纸号和用量；层级 `0` 为顶层型号，后续层级来自真实子 BOM 关系。
5. 下载 BOM 模板后，能看到 `BOM表`、`BOM明细` 及其规定字段；不会把层级、图纸号、状态或成本误做成可绕过校验的写入列。
6. 导入一张 BOM 及多条组件时，生成一张 BOM、多条明细，数量、单位、物料和图纸快照正确。
7. 导入两层结构时，生成对应的多张 BOM 和子 BOM 关联；展开结果正确，不允许循环引用。
8. 不存在的型号/组件物料、单位无效、用量小于等于零、图纸未定稿、图纸号不匹配、重复型号或重复行号均明确报出所在工作表、行号和字段。
9. 已提交 BOM 不会被模板覆盖；变更按照已选定的修订策略保留历史 BOM 与已关联工单的可追溯性。
10. BOM 导入、提交、取消和修订不破坏现有工程图纸、生产工单、采购建议和成本计算链路。

## 9. 实施前待确认项

1. “型号编码”是否确定为 `Item.item_code`。本文按此理解设计；若实际要用外部型号或内部机种，必须先建立唯一、不可变的物料关联规则。
2. 第 4.2 节的版本选项是否采用推荐的 B（首版 `BOM-型号编码`，修订追加后缀）。这是保障历史追溯的关键决策。
3. 截图中黄色和橙色区域是否代表工程阶段、物料分类或变更状态。若有业务含义，应使用独立的受控字段定义，不能把 Excel 填充色直接当作系统数据。
4. “图纸号”是否要求组件无图纸时禁止提交 BOM；本文默认允许为空，但一旦物料关联图纸，则必须为已定稿版本。
5. 多层模板导入是首期必须功能，还是先实施直接组件导入、后续再开放含子 BOM 的多层导入。两者共用数据模型，但多层导入需要额外循环和依赖顺序校验。
