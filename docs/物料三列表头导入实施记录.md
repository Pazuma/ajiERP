# 物料三列表头导入

## 使用方式

物料列表 → 导入 → 下载推荐物料模板，或上传首行为以下三个表头的 Excel：

| 分类 | 物料编码 | 物料名称 |
| --- | --- | --- |
| 电子 | 000001 | 示例物料 |

三个字段必填，列顺序可交换；编码请在 Excel 中使用文本格式保留前导零。
分类必须已存在且是末级物料分类，不自动创建或替换成其他分类。
重复编码、未知分类、缺失值在预览中按 Excel 行号提示。额外列不静默丢弃，须改用标准模板。
新增遇到已有编码会阻止；修改已有物料须选择更新模式，编码直接匹配系统物料编号。

## 新建默认值

| 字段 | 默认值 |
| --- | --- |
| 是否可销售 | 否，分类为成品也不会自动开启 |
| 是否可采购、管理库存、包含在制造中 | 是 |
| 禁用、固定资产、批次号、序列号、变体、允许负库存 | 否 |
| 库存单位 | 库存设置中的默认库存单位；未设置时 Nos，单位须已存在且启用 |
| 库存单位换算系数 | 1，由 ERPNext 自动建立 |
| 描述 | 物料名称 |
| 默认物料申请类型 | 采购 |
| 生命周期截止日期 | 2099-12-31 |
| 期初库存、估值单价、标准售价 | 0，不生成库存流水或价格记录 |

其余沿用站点的物料字段默认值。当前原生非空默认值还包括：允许佣金=是；
供应商直送、委外、客户供料、自动创建资产、组合资产、自动创建批次、有效期管理、
保留样品、采购前质检、交货前质检、替代物料、递延收入、递延费用=否；
最小订购量=0；变体依据=物料属性。
自定义默认值：参与库存减值评估=否，允许转回=是（未启用减值评估时不会启动折旧）。
品牌、供应商、仓库、研发项目、报价单、税费、图纸等不猜测关联，默认空；未设定的数值为 0。

以上默认值仅用于这份三列模板的新建模式。更新模式仅改分类和名称，编码用于定位，
不重置原有销售/采购开关、单位、库存、价格、描述和关联资料。

## 实现文件与链路

- `client_akivision/utils/item_excel_import.py`：识别三列表头、校验、默认值、保存与逐行日志。
- `client_akivision/client_akivision/api/data_import.py`：新增模板下载 API；现有预览和执行入口增加 Item 分支，原模板继续走旧链路。
- `client_akivision/public/js/inline_data_import.js`：物料推荐模板下载、三列预览和默认值提示。
- `client_akivision/utils/test_item_excel_import.py`：真实 XLSX 预览到执行、默认值、更新保留设置、错误拦截和模板测试。

调用：上传 → preview_inline_import → item_excel_import.preview/plan → 确认导入 →
start_inline_import → 后台 run_inline_import → item_excel_import.run → Item.insert/save → ERPNext 原有校验及自定义钩子。

没有修改旧接口参数、全局物料默认值或已有物料；不需要数据库结构迁移。
本地修改需同步代码及前端资源到服务器并重启对应服务后，服务器才生效。
