# 中国财务“四项能力分析表”方案

## 1. 文档状态与目标

- 阶段：方案沉淀，先明确口径和验收效果，再实施代码。
- 目标：在“中国财务 -> 财务分析”增加偿债能力分析、运营能力分析、盈利能力分析、发展能力分析四个独立页面。
- 原则：小增量、只读分析、复用现有财务报表和总账数据、优先新增分支，不修改现有报表接口。

## 2. 需求理解

四张分析表采用参考界面的 Frappe 列表页风格：左侧继续使用中国财务工作区导航，顶部保留标签栏、面包屑、列表视图/已保存筛选器/刷新/更多/新增等系统工具区；筛选条件使用浅灰胶囊式控件，主体使用紧凑的浅灰表头、细分隔线和状态徽标。页面保持 Frappe/ERPNext 原有顶部工具栏、面包屑、筛选控件、表格和权限体系，不复制参考系统品牌、深色侧栏或固定颜色。

本次风格调整以截图中的“税务科目映射”列表为基准：分析页面标题显示在“中国财务 / 财务分析 / <分析表名称>”面包屑中；四类分析表通过列表页内的分析类型切换进入，避免增加重复的 Desk 页面壳。结果区域按列表数据密度呈现，每行包含选择框、指标名称、状态、计算结果、参考值、说明和来源，支持横向滚动及空数据提示。

四个页面共享公司、分析期间、对比期间筛选和下载/打印能力；每张表只负责自己的指标注册表和计算分支。

## 3. 分析指标与口径

### 3.1 偿债能力分析表

| 指标 | 公式 | 默认参考值 |
| --- | --- | --- |
| 资产负债率 | 负债总额 / 资产总额 | 越低长期偿债压力越小 |
| 流动比率 | 流动资产 / 流动负债 | 1.5~2.0 |
| 速动比率 | (流动资产 - 存货) / 流动负债 | 0.6~1.0 |
| 现金比率 | 货币资金 / 流动负债 | 0.2 左右 |

### 3.2 运营能力分析表

| 指标 | 公式 | 默认参考值 |
| --- | --- | --- |
| 存货周转率 | 营业成本 / 平均存货 | 行业或公司历史值 |
| 应收账款周转率 | 营业收入 / 平均应收账款 | 越高通常越好 |
| 应付账款周转率 | 营业成本 / 平均应付账款 | 与供应商账期结合判断 |
| 流动资产周转率 | 营业收入 / 平均流动资产 | 公司历史值 |
| 总资产周转率 | 营业收入 / 平均资产总额 | 公司历史值 |

### 3.3 盈利能力分析表

| 指标 | 公式 | 默认参考值 |
| --- | --- | --- |
| 销售净利率 | 净利润 / 营业收入 | 越高越好 |
| 销售毛利率 | (营业收入 - 营业成本) / 营业收入 | 越高越好 |
| 销售费用占收入比 | 销售费用 / 营业收入 | 与历史、预算比较 |
| 管理费用占收入比 | 管理费用 / 营业收入 | 与历史、预算比较 |
| 资产利润率 | 净利润 / 平均资产总额 | 越高越好 |

### 3.4 发展能力分析表

| 指标 | 公式 | 默认参考值 |
| --- | --- | --- |
| 股东权益增长率 | (期末权益 - 期初权益) / 期初权益 | 与历史期间比较 |
| 利润总额增长率 | (本期利润总额 - 上年同期利润总额) / 上年同期利润总额 | 与历史期间比较 |
| 营业收入增长率 | (本期收入 - 上年同期收入) / 上年同期收入 | 与预算、历史比较 |
| 净利润增长率 | (本期净利润 - 上年同期净利润) / 上年同期净利润 | 与历史期间比较 |

分母为零、缺少期初余额或缺少对比期间数据时，结果显示 `--`，状态标记为“需补充数据”，不返回无意义的 0%。

## 4. 总体设计与调用链路

新增统一只读服务 `get_capability_analysis(company, from_date, to_date, analysis_type, comparison_from_date, comparison_to_date)`，通过白名单将请求分派到四个计算器：

```text
能力分析 Page
  -> get_capability_analysis
  -> 参数、公司权限、分析类型校验
  -> 财务报表/GL 聚合读取
  -> CapabilityCalculatorRegistry 分派
  -> 返回统一指标 rows、状态、警告、来源
  -> 页面渲染表格、下载、打印
```

优先复用 `China Financial Statements` 的汇总逻辑和 ERPNext General Ledger 数据；如某指标需要科目映射，读取既有映射配置，不修改映射接口。后续可增加预算、行业参考值和趋势图，但不改变首期返回字段含义。

页面布局贴合示例：顶部为“中国财务 / 财务分析 / 分析表名称”面包屑和系统工具栏；筛选区使用公司、起止日期、对比期间等浅灰列表筛选控件，并提供过滤条件、刷新、更多操作、下载、打印；正文为紧凑列表表格，表头为浅灰背景，状态使用蓝色启用/已计算徽标，金额/比例右对齐，说明列支持省略和悬停查看。

预期交付效果：

- “财务分析”下可直接打开四个独立分析表，页面标题和导航名称分别为“偿债能力分析”“运营能力分析”“盈利能力分析”“发展能力分析”。
- 四张表保持一致的筛选、表头、状态、下载和打印体验，切换分析表不刷新整个 Desk 页面。
- 指标结果可追溯到财务报表或总账来源；没有可靠数据时显示 `--` 和“需补充数据”，不以 0% 掩盖数据缺口。
- 参考值仅作为辅助判断，不参与会计入账、结账或税务申报，不改变历史账务数据。
- 1440px、1280px、768px 和 390px 视口下无重叠；窄屏时筛选区换行、表格横向滚动，指标名称和结果仍可读。
- 与截图一致的列表页层级：左侧导航高亮“财务能力分析”，顶部标签显示当前分析表，主区域不出现大面积空白卡片或独立品牌装饰。
- 空数据时显示 Frappe 标准空状态和“新建/调整筛选条件”引导；加载时显示列表页级别的计算中状态，失败时保留筛选条件并显示可读错误提示。

### 7.1 风格实施约束

- 仅在 `.cf-capability-analysis` 作用域内覆盖样式，复用 Frappe 的 `btn`、`form-control`、列表表头和状态色变量。
- 不新增圆角卡片嵌套、渐变背景或大字号营销区；表格行高、边框和间距以现有中国财务列表页为准。
- “新增”按钮仅作为列表页统一工具栏样式保留；本期分析数据只读，不创建会计凭证或分析单据。

## 8. 受影响模块与风险

影响模块：China Finance 财务分析导航、财务报表只读聚合、权限和静态资源。销售采购单据、税务、结账、日账簿及既有报表接口不受影响。

风险控制：分母为零返回缺失状态；资产负债表指标按期末/期初口径计算；损益表指标按期间累计口径计算；对比期间由用户明确选择；不将行业参考值硬编码为法定标准；所有公司和日期查询使用参数绑定。

## 9. 实施与验收顺序

1. 先建立统一返回结构和四类计算器的纯计算测试。
2. 新增统一 Page 和表格渲染，首期实现财务报表/总账可取得指标。
3. 增加导航、权限和局部 CSS，执行 migrate/build/clear-cache。
4. 用真实公司和期间核对四表结果，与现有财务报表交叉验证。
5. 验收下载、打印、缺失数据、分母为零、无权限和多视口表现。

## 10. 回滚

移除新增 Page、计算服务、测试、CSS 和导航链接，再执行迁移、构建和缓存清理。首期仅读，不生成凭证、不写入账务，因此回滚不影响历史数据。
