# 中国财务凭证业务链路测试记录

## 1. 测试目标与结论

本轮按 `51-china-finance-complete-test-plan.md` 场景 A 执行“新增凭证 -> Journal Entry -> GL Entry -> 中国会计凭证及分录快照”真实用户流程，并检查现金流量指定后续状态。

结论：凭证主链路通过。页面成功提交正式凭证，ERPNext 总账和中国会计凭证快照金额一致且各出现一次。现金流量指定未生成，原因已确认是目标公司未设置现金流量直接指定启用日期，属于已知配置阻塞，不是本次凭证过账失败。

## 7. 发现的问题和优化建议

### 7.1 公司控件自动化定位不稳定

现象：页面能显示默认公司，但顶部 Frappe Page 字段不暴露稳定的可见 input，通用 Playwright 定位超时。

当前解决：使用页面默认公司，提交后核对 Journal Entry.company，避免误测其他公司。

优化方案：给页面公司字段容器增加稳定 `data-testid`，并在页面加载完成后显示明确的当前公司文本；测试必须在点击记账前断言公司，不能只依赖默认值。

### 7.2 页面摘要字段重复录入

现象：当前服务以第一条有摘要的分录作为 Journal Entry 主摘要，每行仍独立填写。

优化方案：页面增加“凭证摘要”主字段，新行默认继承主摘要，同时保留逐行覆盖能力，减少重复输入且不修改后端接口。

### 7.3 现金流启用配置阻塞不可忽略

原因：目标公司启用日期为空，所以即使凭证包含银行科目和外部对手科目，也不会产生现金流指定单。

解决方法：由财务负责人确定启用日期，在“中国财务设置”保存后，使用启用日之后的新凭证继续测试。不能把本次历史凭证是否补生成指定单作为默认预期。

优化方案：设置页已有只读配置状态提示；可进一步在新增凭证页面增加非阻断提示“该公司未启用现金流量直接指定”，但不应阻止正常记账。

## 8. 人工复测步骤

1. 打开“新增凭证”，确认公司明确显示为 `阿基视觉（东莞）`。
2. 使用新的唯一摘要，例如 `CF-MANUAL-20260907-01`，不要重复使用本次自动化标识。
3. 借记 `100201 - 基本存款账户 - T` 100.00，贷记 `6001 - 主营业务收入 - T` 100.00。
4. 确认页面借贷合计相等后点击“保存并记账”。
5. 记录 Journal Entry 编号，确认状态为已提交。
6. 在总账中按 Journal Entry 编号查询，确认只有两条有效分录。
7. 打开对应中国会计凭证，核对法定编号、两条快照分录和借贷合计。
8. 在查凭证、凭证汇总、会计总账和日账簿中按摘要或凭证号查询，确认金额只出现一次。
9. 财务负责人配置现金流启用日期后，再新建一张启用日之后的凭证；确认自动生成现金流量指定单。
10. 对指定单执行保存、确认、报表核对、作废和重建，记录每一步状态和金额。
