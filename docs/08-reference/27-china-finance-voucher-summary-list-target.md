# 凭证汇总表列表区域目标效果确认稿

> 状态：目标效果确认，本轮不继续修改代码  
> 日期：2026-09-02  
> 页面：`/app/china-voucher-summary`

## 1. 目标

将凭证汇总表的科目结果区域由普通报表表格调整为与系统销售订单 List View 一致的列表形式。重点统一表头高度、字段间距、行分隔、悬停状态和空数据表现，而不是简单改变四列宽度。

## 2. 目标结构

```text
0 张凭证   0 张附件   借方合计 0.00   贷方合计 0.00

┌──────────────────┬──────────────────┬──────────────────┬──────────────────┐
│ 科目编码         │ 科目名称         │         借方金额 │         贷方金额 │
├──────────────────┼──────────────────┼──────────────────┼──────────────────┤
│ 1001             │ 库存现金         │         1,000.00 │             0.00 │
│ 1002             │ 银行存款         │             0.00 │         1,000.00 │
│                  │ 流动资产小计     │         1,000.00 │         1,000.00 │
└──────────────────┴──────────────────┴──────────────────┴──────────────────┘
```

无数据时：

```text
┌──────────────────┬──────────────────┬──────────────────┬──────────────────┐
│ 科目编码         │ 科目名称         │         借方金额 │         贷方金额 │
└──────────────────┴──────────────────┴──────────────────┴──────────────────┘

                                  [列表图标]
                              当前期间暂无凭证汇总数据
```

## 3. 与系统 List View 对齐

- 表头使用单层、紧凑的列表头带，不使用高饱和蓝色或大块表格边框。
- 表头高度约 `42px`，数据行高度约 `42px`。
- 表头和数据单元格统一使用 `12px` 左右内边距。
- 表头使用系统正文色和 `font-weight: 600`，背景使用 `var(--subtle-fg)`。
- 表头上下边界及每行底部使用 `var(--border-color)` 分隔。
- 数据行悬停使用系统 `var(--highlight-color)`，效果与销售订单列表一致。
- 表头在结果区域滚动时保持可见。
- 不加入选择框、收藏、评论、分页数量等销售订单专属操作，因为凭证汇总行没有对应批量业务。

## 4. 字段规则

| 字段 | 宽度 | 对齐 | 行为 |
|---|---:|---|---|
| 科目编码 | 25% | 左对齐 | 单行显示，过长省略 |
| 科目名称 | 25% | 左对齐 | 单行显示，过长省略并显示 tooltip |
| 借方金额 | 25% | 右对齐 | 使用系统金额格式 |
| 贷方金额 | 25% | 右对齐 | 使用系统金额格式 |

四列保持等宽，以解决当前视觉不均衡；文字与金额通过不同对齐方式体现字段性质。

## 5. 汇总与小计

- 凭证数、附件数、借方合计和贷方合计只在列表上方展示一次。
- 不在列表底部重复生成合计行，减少信息重复。
- “显示科目分类小计”打开后，小计作为普通列表行插入对应科目组末尾。
- 小计行使用浅灰背景和半粗字体，不使用独立卡片或彩色条。

## 6. 空状态和高度

- 无数据时保留列表表头，让用户仍能理解结果字段。
- 空状态位于可用内容区域中部，使用系统列表图标和弱化文字。
- 不把“无数据”放进一个跨四列的表格单元格。
- 列表区域最小高度根据剩余视口计算，避免只剩一条狭窄表头或产生突兀边框。
- 移动端允许横向滚动，四列保持稳定宽度，不压缩金额到换行。

## 7. 计划修改文件

| 文件 | 计划调整 |
|---|---|
| `china_finance/page/china_voucher_summary/china_voucher_summary.js` | 使用独立列表类名、删除重复表尾合计、保留表头与独立空状态 |
| `china_finance/public/css/china_voucher_summary.css` | List View 表头、行高、间距、分隔线、悬停、吸顶和响应式样式 |
| `china_finance/services/voucher_summary.py` | 不修改 |

## 8. 调用链路

```text
筛选或刷新
  -> get_voucher_summary（保持不变）
  -> render_metrics（汇总信息）
  -> render_table
       -> 有数据：列表行 + 分类小计行
       -> 无数据：保留表头 + 居中空状态
```

## 9. 受影响范围

仅影响凭证汇总表结果区域的 DOM 和局部 CSS。不影响汇总服务、筛选参数、下载、打印、凭证附件中心、查凭证和任何凭证数据。

## 10. 预期效果

修改完成后，红框区域会像销售订单列表一样呈现为清晰、连续、可扫描的系统列表：表头不再显得松散或漂浮，四列边界和对齐关系明确，数据行有稳定分隔和悬停反馈。

有数据时，用户可以快速横向比较科目和借贷金额；无数据时，页面仍保留字段结构并显示居中空状态。整体视觉与系统其他 List View 一致，同时保留凭证汇总场景需要的简洁性。
