# 税费计算表缺项修复实施记录

日期：2026-10-23。对应 [92 号修复方案](./92-tax-worksheet-missing-data-diagnosis-and-repair-plan.md)。

## 已实施

- 保留原查询接口，补充来源数量、缺项状态及金额/百分比/人数单位；无来源不再仅显示无解释的零。
- 销项钻取限定销项和非作废，抵扣钻取限定所属月范围及 Deducted；台账新增可选排除作废，旧默认保持。
- 在现有页面增加“维护本期数据”。System Manager、Accounts Manager、China Finance Manager 可维护；原税务查询角色和审计仍可查询，不增加写权限。
- 新增 China Tax Worksheet Snapshot 和服务端 POST 保存接口。每次保存创建独立版本，保留依据、人工值、计算结果及来源记录摘要；不允许普通表单修改或删除。来源/版本冲突会提示刷新。
- 人工值替代对应自动行，留空恢复自动来源，明确填写 0 表示经财务核实的零。无来源且未维护的项目不能确认。
- 常规一般纳税人、无减免无预缴场景可勾选计算；其他场景及六类税种支持财务填写完整人工底稿和依据、复核确认，不内置未经核实的税率或通用公式。
- CSV 附公司、单位、来源、依据、版本和复核人；页面打印沿用页面中的来源提示和版本信息。

入口：中国财务 → 税费计算表 → 选择公司/月份/税种 → 维护本期数据 → 填值及依据 → 保存草稿或复核并确认。确认代表底稿复核完成，不触发申报、记账或缴税。

## 本次交付边界

本次完成方案 A 及可用的人工底稿/VAT 常规计算增量。为了减少表结构及旧流程改动，人工维护、确认快照及来源摘要合并保存在一个新增版本表中，尚未拆成政策规则、调整表和快照子表。

独立政策配置中心、附件登记、前期留抵自动结转、六税种自动来源与计算器、季度/年度专用查询仍属于后续增量；当前由财务在依据中说明真实期间和政策。月度页面不是季度或年度自动申报工具。未形成税票/抵扣的现场数据未被自动补造或提交。
