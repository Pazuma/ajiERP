# BOM 版本下拉查看实施记录

日期：2026-10-12。测试站点：aki_test.localhost。

## 实现效果

“关联”后的“版本”页签已改为版本下拉框，默认选择可访问的当前启用版本。下拉显示版本号、状态及首次启用时间；草稿显示尚未启用，缺少历史时间显示未记录。

选择版本后在页签内显示业务编码、实际单号、版本状态、首次启用时间、公司、产出数量，组件明细严格为“型号、层级、物料名称、图纸号、用量”五列。型号/名称/图纸优先使用导入保存的原始信息，缺失时回退到标准字段。层级从顶层0递增，子层用量按选中顶层产出数量累计换算。

不展示工序、废料或工程资料区域，成本估算按方案保留折叠区。查看不更新成本或默认版本，不写入当前表单组件。提供打开具体版本详情链接。快速切换采用请求序号避免旧请求覆盖新选择。

新增首次启用时间字段，成功标准提交且成为当前有效默认版本后记录，与提交同事务回滚。首次草稿、新更新草稿不继承旧时间。标准保存校验拒绝人工更改该字段。旧历史数据未回填。

## 文件与调用

应用根目录：development/frappe-bench/apps/client_akivision。

- client_akivision/public/js/bom.js：下拉选择、只读详情、五列表格、状态及错误处理。
- client_akivision/client_akivision/api/bom.py：原列表追加状态/时间字段及公司限定，新增 get_bom_version_view(bom, version_bom)。新接口校验两张单据读取权限与同物料/公司/业务编码，逐层检查子 BOM 权限。
- client_akivision/utils/bom_version.py：字段安装、时间保护、record_activation 提交事件。
- client_akivision/hooks.py：追加 BOM on_submit 记录事件，保留旧事件。
- client_akivision/utils/test_bom_version.py：时间、只读详情、五列返回和权限验证。

旧接口参数及旧返回字段保持，新增详情不返回工序、废料或附件。遇到循环、无权限或失效子 BOM停止该分支并提示，不改用最新子版本。

## 业务流程

```text
打开 BOM → 版本页签 → 默认选择当前启用版
  ↓ 下拉选择 V1/V2/草稿
校验读取权限及版本归属 → 加载所选版本五列明细和启用时间
  ↓
仅查看，不改变默认版本、不改变工单

修改前工单 → 固定旧 bom_no → 原清单领料/生产/入库
修改后新工单 → 当前默认 bom_no → 新清单领料/生产/入库

已有更新流程 → 新版草稿 → 保存并启用 → 标准提交和默认管理
  → 成功记录首次启用时间 → 版本下拉刷新
```

## 验证与边界

定向安装字段并清缓存完成，BOM脚本 Node 语法与修改文件空白检查通过。6个原/新版相关事务测试通过，补充无权限详情测试后新版3个测试再次运行。测试数据回滚，不保留临时版本或工单。

测试覆盖启用时间记录与禁止人工清空、五列详情返回、组件量、默认状态、旧工单固定引用、草稿切换和Guest读取拒绝。未做真实浏览器点击验收及多层复杂样本/并发端到端验收。

本次只实现版本查看与首次启用时间，不实现BOM主列表聚合和直接编辑弹窗；标题继续沿用统一业务编码。标准导出仍针对当前打开单据，要导出下拉选择的版本需先打开其详情。首次时间不是反复恢复默认的最近时间。
