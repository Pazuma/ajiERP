# 销售数据面板核心指标优化方案

## 1. 背景与目标

当前销售数据面板沿用 ERPNext 标准 Selling 工作区，包含“年度销售额、待出货销售订单、待开票销售订单、活跃客户”等卡片。现有“年度销售额”使用 `Sales Order.modified` 作为时间条件，可能出现销售趋势有数据而年度销售额为 0 的口径不一致问题；同时缺少“整单已完成”和清晰的订单状态分布。

本方案拟以销售订单为核心，新增并统一以下指标：

- 总销售额；
- 整单已完成；
- 销售订单状态。
- 订单状态分布。

本阶段只沉淀方案，不修改业务代码和标准 ERPNext 文件。

## 2. 指标口径

### 2.1 总销售额

默认统计当前会计年度内已提交、未取消的销售订单：

```text
总销售额 = Sales Order.base_grand_total 合计
```

默认条件：

- `docstatus = 1`；
- `status` 不为 `Cancelled`、`Closed`；
- 日期字段使用 `transaction_date`，不使用 `modified`；
- 公司使用当前用户默认公司；
- 金额使用公司本位币 `base_grand_total`。

如业务确认“销售额”必须以财务收入为准，可在后续增加“已开票销售额”指标，但不与本方案的订单总额混用。

### 2.2 整单已完成

整单已完成定义为：

```text
Sales Order.docstatus = 1
且 per_delivered >= 100
且 per_billed >= 100
且 status 不为 Cancelled、Closed
```

核心展示：

- 已完成订单数；
- 已完成订单金额；
- 完成率 = 已完成订单数 / 有效订单总数。

服务类或不需要送货的订单，如后续需要特殊处理，应另增加可配置规则；第一阶段严格要求送货和开票均完成。

### 2.3 订单状态

建议将标准订单状态和履约比例归并为业务状态：

| 业务状态 | 判断条件 |
|---|---|
| 待送货且待开票 | `per_delivered < 100` 且 `per_billed < 100` |
| 待送货 | `per_delivered < 100` 且 `per_billed >= 100` |
| 待开票 | `per_delivered >= 100` 且 `per_billed < 100` |
| 整单已完成 | `per_delivered >= 100` 且 `per_billed >= 100` |
| 已关闭 | 标准 `status = Closed` |
| 已取消 | `docstatus = 2` 或标准 `status = Cancelled` |

状态图表同时展示订单数量和订单金额，并支持点击跳转到带过滤条件的销售订单列表。

## 3. 面板布局

第一行核心数字卡：

```text
总销售额 | 有效订单数 | 整单已完成 | 销售订单状态
```

第二行图表：

```text
订单状态分布 | 月度销售趋势
```

第三行明细：

```text
待送货订单 | 待开票订单 | 超期未完成订单
```

现有“活跃客户”可移至客户分析工作区，或保留为次要指标，不占用销售履约核心卡片位置。

### 3.1 销售订单状态指标

“销售订单状态”建议作为一个独立的状态汇总卡或状态分布组件显示，而不是只显示单一数量。组件至少展示：

- 各状态订单数量；
- 各状态订单金额；
- 各状态占有效订单比例；
- 点击状态后跳转到对应销售订单列表。

建议显示形式：

```text
销售订单状态
待送货且待开票：15 单
待送货：8 单
待开票：5 单
整单已完成：12 单
已关闭：3 单
已取消：不计入有效订单，可单独查看
```

状态统计应与“整单已完成”使用同一套后端判断方法，避免卡片和图表出现数量不一致。

## 4. 调用链路

```text
销售工作区 Selling
    ↓
加载数字卡片/图表配置
    ↓
读取当前用户默认公司和会计年度
    ↓
查询已提交销售订单
    ↓
按 transaction_date 过滤时间范围
    ↓
汇总 base_grand_total、per_delivered、per_billed、status、docstatus
    ↓
计算总销售额、整单完成数、完成率、销售订单状态、状态分布
    ↓
渲染卡片和状态图表
    ↓
点击状态跳转销售订单列表
```

## 5. 计划修改的代码和文件

以下是实施阶段的预定修改范围，本次文档阶段不修改这些文件。

### 5.1 数字卡片

优先新增自定义数字卡片，避免直接修改 ERPNext 标准卡片：

- `client_akivision` 中新增销售总额数字卡配置；
- 新增整单已完成数字卡配置；
- 新增整单完成率数字卡配置；
- 将年度销售额卡片替换为新口径，或通过工作区分支引用新卡片。

建议使用独立名称，例如：

- `Client Annual Sales Total`；
- `Client Fully Completed Sales Orders`；
- `Client Sales Order Completion Rate`。

### 5.2 订单状态图表

- 新增销售订单状态分布 Dashboard Chart 或 Query Report；
- 新增后端统计方法，统一返回状态、订单数量、订单金额；
- 增加状态点击跳转过滤参数。

### 5.3 销售订单状态指标

- 新增“销售订单状态”指标卡或状态汇总组件；
- 复用订单状态统计接口返回的状态数量、金额和占比；
- 支持按状态跳转销售订单列表；
- 有效订单状态和取消订单分开处理，避免取消订单混入销售额和完成率。

### 5.4 工作区配置

- 新增或覆盖销售工作区的自定义配置；
- 第一行替换为总销售额、有效订单数、整单已完成、整单完成率；
- 保留现有销售趋势图，统一日期和金额口径；
- 将状态分布图加入工作区。

### 5.5 后端公共逻辑

建议新增独立模块，例如：

```text
client_akivision/utils/sales_dashboard_metrics.py
```

负责：

- 获取默认公司和当前会计年度；
- 统计销售订单金额；
- 统计完整送货并完整开票订单；
- 统计状态分布；
- 返回销售订单状态汇总；
- 复用统一过滤条件。

旧报表和旧接口不直接改写，新的数字卡和图表通过新增方法调用。

## 6. 受影响模块

| 模块 | 影响 | 处理方式 |
|---|---|---|
| 销售工作区 | 卡片和图表布局调整 | 新增工作区分支或自定义配置 |
| 销售订单 | 读取金额、状态、送货和开票进度 | 只读统计，不改订单数据 |
| 销售趋势 | 日期口径统一 | 新分支使用 `transaction_date` |
| 销售订单列表 | 状态点击跳转 | 增加过滤参数，不改列表接口 |
| 销售订单状态 | 状态数量、金额和占比 | 新增状态汇总指标，复用统一统计逻辑 |
| 公司/会计年度 | 提供默认公司和日期范围 | 复用现有标准函数 |
| 权限 | 统计结果受用户权限影响 | 使用当前用户可见销售订单 |
| 翻译 | 指标名称中文化 | 增加应用翻译，不修改标准语言包 |

## 7. 小增量与兼容策略

1. 不直接修改 ERPNext 标准数字卡和标准报表文件。
2. 优先新增数字卡、状态图表和后端统计方法。
3. 保留原有 `Annual Sales`、`Sales Order Trends` 等标准对象，必要时仅在自定义工作区中替换引用。
4. 新统计接口使用可选过滤参数，旧接口不传参数时行为不变。
5. 总销售额统一使用 `base_grand_total` 和 `transaction_date`，避免继续使用 `modified`。
6. 状态判断集中在一个后端方法中，避免数字卡和图表各自实现不同口径。
7. 所有查询只读，不改销售订单状态、不回写业务单据。

## 8. 预期效果

实施后，销售数据面板第一屏能够直接回答：

- 当前会计年度销售订单总额是多少；
- 有多少有效销售订单；
- 有多少订单已完成全部送货和开票；
- 订单当前主要处于待送货、待开票还是已完成状态。
- 各销售订单状态的数量、金额和占比。

同时达到以下效果：

- 总销售额与销售趋势使用一致的日期和金额口径；
- 不再因使用 `modified` 导致年度销售额显示为 0；
- 整单完成定义明确，可追踪订单履约结果；
- 销售订单状态在数据面板集中展示，并可下钻到明细订单；
- 状态图表可下钻到具体销售订单；
- 多币种订单统一按公司本位币展示；
- 原有标准销售订单、销售趋势和列表功能保持兼容；
- 指标查询只读，不影响销售业务数据。

## 9. 验收标准

- 当前会计年度存在已提交销售订单时，总销售额不再无故显示 0；
- 总销售额等于符合条件订单的 `base_grand_total` 合计；
- `per_delivered = 100` 且 `per_billed = 100` 的订单计入整单已完成；
- 任一比例未达到 100% 的订单不计入整单已完成；
- 状态分布数量之和等于筛选范围内订单总数；
- 状态金额之和与有效订单金额一致；
- 销售订单状态指标与状态分布图数量、金额一致；
- 点击任一销售订单状态可正确过滤并打开销售订单列表；
- 点击状态可打开对应销售订单列表；
- 切换公司和会计年度后，所有卡片和图表同步变化；
- 无权限订单不会泄露到统计结果中。
