# 业务表单总表页面未找到修复记录

## 问题现象

指标看板侧边栏已显示“业务表单总表”，点击后提示 `business-form-overview` 页面未找到。

## 原因

侧边栏入口由启动会话动态注入，但新增 Page 的 JSON 文件没有在目标站点数据库中生成 `Page` 记录。Frappe 路由依赖数据库中的 Page 记录，因此出现“菜单存在、页面不存在”。

## 修复内容

- 在 `sync_operations_management_desktop_icon` 迁移同步链路中增加幂等的 `ensure_business_form_overview_page`。
- 页面不存在时自动创建 `Page` 记录，已存在时不重复创建。
- 保留原运营指标看板接口和侧边栏逻辑。

## 修改文件

- `apps/client_akivision/client_akivision/utils/operations_management.py`
- `apps/client_akivision/client_akivision/client_akivision/page/business_form_overview/business_form_overview.json`

## 生效操作

在容器内执行：

```bash
cd /workspace/development/frappe-bench
bench --site aki_test.localhost migrate
bench --site aki_test.localhost clear-cache
bench --site aki_test.localhost clear-website-cache
```

完成后强制刷新浏览器。预期点击菜单可正常打开业务表单总表页面。
