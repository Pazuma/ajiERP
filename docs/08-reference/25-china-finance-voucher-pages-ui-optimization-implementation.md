# 中国财务凭证页面界面优化实施记录

> 状态：已实施  
> 日期：2026-09-02  
> 对应方案：`23-china-finance-voucher-summary-ui-optimization-plan.md`、`24-china-finance-voucher-attachment-center-ui-optimization-plan.md`

## 1. 实施范围

本次仅调整“凭证汇总表”和“凭证附件中心”的前端结构与局部样式。没有修改凭证汇总服务、附件查询服务、凭证 DocType、电子档案数据和旧接口。

## 2. 已修改文件

| 文件 | 实际修改 |
|---|---|
| `china_finance/page/china_voucher_summary/china_voucher_summary.js` | 重构为页面类；新增标准筛选控件、互斥期间模式、操作菜单、刷新按钮、状态与运行时间、汇总带、居中空状态 |
| `china_finance/public/css/china_voucher_summary.css` | 改为六列报表筛选网格、中性表头、系统主题变量、响应式布局 |
| `china_finance/public/css/china_voucher_attachment_center.css` | 附件行改为连续列表表现；主容器占用剩余视口；表头吸顶；分页栏推至内容区底部 |

## 3. 凭证汇总表效果

- 原大块灰色筛选面板改为与“查凭证”一致的筛选网格。
- 宽屏桌面端六列一行、普通桌面端三列两行、中屏两列、移动端单列；通过页面局部高优先级选择器避免 Frappe 默认表单宽度将字段拉成整行。
- 期间模式切换会隐藏整个网格项而不只隐藏控件内部，隐藏字段不再占列；六个有效字段可真正排满一行。
- 查询状态和运行时间已合并到汇总信息行，删除筛选区与汇总区之间的独立状态留白。
- “按月”和“自定义日期”互斥显示、互斥提交，后端参数保持原格式。
- 下载和打印进入页面右上“操作”菜单；增加带刷新图标的刷新按钮。
- 查询状态行显示生成状态、完成状态和运行时间。
- 凭证数、附件数、借贷合计和查询区间使用紧凑汇总带展示。
- 表格使用浅灰中性表头、固定列宽、金额右对齐、悬停状态和分类小计行。
- 科目编码、科目名称、借方金额、贷方金额四列统一为 `25%`，消除表头宽度失衡；文字列左对齐，金额列右对齐。
- 科目区域进一步改为系统 List View 风格：紧凑表头带、统一水平内边距、连续分隔线、表头吸顶及列表行悬停反馈。
- 删除表格底部重复合计行，借贷合计继续由列表上方的汇总信息行统一表达。
- 无数据时继续保留列表表头，居中空状态从表头下方开始展示；科目编码和名称增加完整内容 tooltip。
- 空状态改由组件直接控制显示，并设置独立背景与层级，避免全局 `.hidden` 规则或表格层叠导致提示消失。
- 空数据改为页面中部图标状态，并在存在关键词时提供“清除关键词”。

## 4. 凭证附件中心效果

- 附件以每行一条记录的列表形式展示，字段和操作保持不变。
- 列表使用页面剩余高度，少量数据不会导致分页栏停在页面中部。
- 总数、上一页和下一页位于内容区底部。
- 数据较多时列表主体滚动，表头保持可见，分页栏保持在底部。
- 移动端恢复自然布局高度，避免视口计算造成遮挡。

## 5. 调用链路

```text
凭证汇总表筛选/刷新
  -> get_voucher_summary（未修改）
  -> render_metrics
  -> render_table / render_empty_state
  -> 下载与打印复用最近一次成功结果

凭证附件中心筛选/分页
  -> get_voucher_attachments（未修改）
  -> render_rows（业务逻辑未修改）
  -> CSS 列表主体伸展
  -> footer 自然贴合内容区底部
```

## 6. 兼容性与受影响模块

- 旧路由保持：`/app/china-voucher-summary`、`/app/china-voucher-attachment-center`。
- `get_voucher_summary`、`get_voucher_attachments` 请求和返回结构不变。
- 上传、预览、下载、验真、凭证跳转和分页逻辑保持不变。
- 不影响新增凭证、查凭证、凭证快照、电子会计档案、财务报表和结账模块。
- CSS 选择器限定于 `.cf-voucher-summary` 和 `.cf-attachment-center`，不污染其他 Desk 页面。

## 7. 验证结果
