# 中国现金流量指定与来源单据建议方案

## 1. 背景与问题

现金流量指定单用于将已过账凭证中的现金、银行分录归类到现金流量表项目。当前页面把“来源单据类型”定义为可任意选择的 `DocType`，导致系统全部 DocType 出现在下拉框；同时空白新建表单缺少来源凭证，用户难以理解页面用途。

当前数据库中的 17 张指定单均已正确对应 `Payment Entry` 或 `Journal Entry`、中国会计凭证及有效 GL Entry。本方案不清洗历史数据，只优化入口、交互和生成规则。

## 2. 目标

1. 让用户明确现金流量指定是“现金流量表分类”，不是收付款或会计凭证。
2. 来源单据由系统从中国会计凭证自动带入，不允许手工选择或修改。
3. 在来源单据上提供现金流量项目建议，减少简单业务的重复录入。
4. 支持一笔现金金额拆分到多个现金流量项目，并保证金额不重复、不遗漏。
5. 保留指定人、确认人、修订版和来源链路，满足审计追溯要求。

## 3. 业务边界

### 3.1 来源单据

现金流量指定单的直接来源是已提交的中国会计凭证；中国会计凭证再关联业务来源：

```text
现金流量指定单
  -> 中国会计凭证
  -> 来源单据（收付款单或会计凭证等）
  -> 有效 GL Entry
```

“来源单据类型”和“来源单据”均为只读字段。当前正式现金流量指定数据主要使用：

| 类型 | 系统值 |
| --- | --- |
| 收付款单 | `Payment Entry` |
| 会计凭证 | `Journal Entry` |

其他业务单据可以作为总账追踪来源，但不应在现金流量指定页面作为任意可选类型展示。

### 3.2 来源建议与最终指定

来源单据上的现金流量项目字段只表示“建议值”，最终报表取数以现金流量指定单中已确认的明细为准。这样既简化单一项目场景，又保留复杂业务的拆分能力。

## 4. 页面与交互方案

### 4.1 来源单据表单

在收付款单、会计凭证等现金相关来源表单增加：

- 现金流量项目建议；
- 建议状态：未生成、待确认、已确认、需拆分；
- 现金流量指定单链接。

建议字段不改变总账金额，不直接写入现金流量表。

### 4.2 现金流量指定工作台

现金流量指定单不提供普通空白新建入口，只能从已提交的中国会计凭证或来源单据进入。

顶部显示只读信息：公司、记账日期、中国会计凭证、来源类型、来源单据、可指定金额、已指定金额、未指定金额。

明细区保留用户真正需要操作的字段：

| 字段 | 规则 |
| --- | --- |
| 现金/银行科目 | 系统带入，只读 |
| 现金发生额 | 系统带入，只读 |
| 收付方向 | 系统带入，只读 |
| 系统建议项目 | 系统计算，只读 |
| 实际现金流项目 | 从当前公司有效模板末级项目中选择 |
| 指定金额 | 可编辑，必须大于零 |

GL Entry 编号、内部行代码、对手方科目等技术字段默认隐藏，可在“技术详情”中查看。

## 5. 自动生成与确认规则

1. 来源单据提交并生成正式中国会计凭证后，系统识别现金/银行分录。
2. 若只有一个有效现金流项目建议，且建议金额等于现金发生额，则生成指定草稿并可自动确认。
3. 若存在多个对手方、多个现金流项目、内部划转或建议金额不完整，则生成草稿并要求人工确认或拆分。
4. 指定金额合计必须等于每一条现金/银行 GL Entry 的现金发生额。
5. 未确认指定不得计入现金流量表；确认后才参与报表汇总。
6. 来源单据或来源凭证作废时，关联指定单自动作废。
7. 已确认或已作废指定单不可修改；需要调整时生成新的修订版。

## 6. 数据与接口约束

- `source_doctype`、`source_name`、`china_accounting_voucher` 由系统派生并只读。
- 后端校验来源单据存在且已提交。
- 后端校验来源类型、来源编号、公司、记账日期与中国会计凭证一致。
- 创建接口仅接受已提交且包含现金分录的中国会计凭证。
- 不允许通过导入或 API 绕过页面创建无来源指定单。
- 现金流量模板按公司和记账日期确定，项目必须是有效末级项目。

## 7. 实施步骤

1. 在来源单据中增加现金流量项目建议及指定单状态/链接。
2. 增加建议计算服务，复用现金科目范围和现金流量模板。
3. 改造指定单创建服务，统一从中国会计凭证生成草稿。
4. 优化指定单页面，移除来源类型下拉选择和空白新建入口。
5. 增加单一项目自动确认、多项目拆分、内部划转和来源作废处理。
6. 对历史指定单执行只读兼容，不修改已有来源关系。

## 8. 验收标准

- 页面不再显示全部系统 DocType。
- 空白新建路由被拦截并提示正确入口。
- 收付款单或会计凭证提交后可自动生成指定草稿。
- 单一项目且金额完整的业务无需重复录入即可确认。
- 复杂业务可以拆分多个现金流量项目，金额校验准确。
- 来源类型、来源单号、凭证和 GL Entry 可逐级跳转且相互一致。
- 来源单据作废后指定单不再计入现金流量表。
- 现有 17 张指定单数据保持不变。
