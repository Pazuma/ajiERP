# 收付款凭证紧凑布局

## 实现效果

- 基本信息三列：付款类型、过账日期、公司；往来单位、往来单位名称、付款方式；凭证字号、银行交易参考号、参考日期。字段是否展示仍由原生规则决定，往来单位类型保留供新建时选择。
- 金额概况四列：付款/收款金额、已分配、未分配、差异。内部转账及不同账户币种需要的收款金额继续按原生规则显示。
- 原生关联单据表整行展示，保留选择发票、分配和跳转行为。
- 会计科目与汇率、更多设置、回款业务信息、备注与打印设置折叠；缺少必填项时沿用原生展开机制。
- 窄屏自动降为两列、单列；税费、扣款、现金流量等扩展区域保留。

## 修改文件与调用链

- `client_akivision/hooks.py`：增加 Payment Entry 前端脚本注册。
- `client_akivision/public/js/payment_entry_layout.js`：refresh 首次执行布局，移动原生字段控件到现有分组，维护字段的 section 归属，注入限定范围样式。后续 refresh 不重复生成布局。

调用链：Payment Entry 表单加载 → Frappe 加载各应用 doctype_js → 原生业务脚本及中国财务脚本继续执行 → 本脚本重排原生控件 → 原生计算、权限、显示依赖及关联单据操作继续使用原实例。

不增加数据库字段，不修改支付业务接口、金额计算、账务处理及权限。只影响桌面表单，不改变打印格式。
