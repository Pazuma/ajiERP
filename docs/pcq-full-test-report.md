## 录入模块、入口及顺序

菜单名称可能按人员视角不同；找不到菜单时可用顶部全局搜索输入括号内单据名称。

| 顺序 | 模块和入口 | 录入流程与本次数据 |
|---|---|---|
| 1 | 基础资料 → 物料与库存 → 物料表（Item） | 新建原料PCQ-UAT-1022-RAW、成品PCQ-UAT-1022-FG，单位Nos，库存物料。 |
| 2 | 物料表 → 原料 → 供应商明细 | 添加供应商2，维护供应商阶梯价格；本次规则ISPR-00008，固定未税15元/Nos、CNY、有效期2026-10-01至2027-10-31。务必把规则关联到供应商行的当前价格规则，仅建规则不会被报价读取。 |
| 3 | 基础资料 → 物料与库存 → BOM汇总（BOM） | 新建BOM-PCQ-UAT-1022-FG，1件成品耗2件原料，保存并提交，设为默认、启用。 |
| 4 | 项目 → 项目（Project） | 新建PROJ-0012，成本明细填写测试费2000元；开发预算填写直接投入费3000元，仅作预算参考。 |
| 5 | 库存 → 库存对账（Stock Reconciliation） | 本次为测试建期初库存MAT-RECO-2026-00005：原料20件，单价15元，仓库 - T，提交。实际采购业务应通过采购入库记录库存。 |
| 6 | 生产 → 生产工单（Work Order） | MFG-WO-2026-00065，数量10，引用测试BOM，填写原料仓/在制仓/成品仓，实际工时3小时、费率60元，提交。 |
| 7 | 生产工单 → 创建生产入库（Stock Entry） | 选择入库方向“入库”、原因“生产入库”，完成数量10；核对原料20件出库、成品10件入库后提交。本次MAT-STE-2026-00092。 |
| 8 | 基础资料 → 物料与库存 → 产品成本报价单 | 新建，选成品、BOM、项目和参考工单，填客户、币种、税率、毛利率和批量；点击“读取来源 / 刷新预览”，核对并“应用选中分组”。 |
| 9 | 报价单 → 成本核算 | 材料确认采购价格含税口径；制造填写0.3小时×60元；项目实际费用分摊100%、剩余1000元、摊销500台；预算行剩余为0。保存并核算，确认估算依据后提交。 |
| 10 | 报价单 → 导出 | 选择内部完整核算表或客户报价单。后续变更用“复制为新版本”，重新读取来源并确认口径。 |

刷新来源会重建被选中的来源明细，材料含税口径、项目分摊等需要重新核对；无来源键的手工制造行已验证保留。人工测试草稿已重新补齐这些字段。
