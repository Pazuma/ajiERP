# 中国财务成本汇总表口径确认

日期：2026-10-16。状态：口径暂定，仅沉淀文档，未实施业务代码。

## 已确认方向

在中国财务模块增加成本汇总表，覆盖生产工单成本、销售订单成本与毛利，支持财务追溯核对。

| 项目 | 暂定口径 |
| --- | --- |
| 人工 | 使用生产工单实际人工成本，不采用计划人工替代 |
| 生产成本 | 使用工单对应的实际生产成本，追溯制造入库凭证 |
| 收入 | 按已提交销售发票不含税金额，以发票过账日期归属期间；退货及红字冲减 |
| 在制品 | 分配规则暂未确定；先单列未完工工单，不强行结转 |

工单生产成本中已包含的人工及附加费用只拆分展示，不重复加总。父子工单成本避免重复累计，根工单已经消耗的半成品成本不再次追加子工单成本。

## 报表内容

1. 工单成本：公司、工单、父/根工单、产品、关联销售订单、完工数量、实际人工、生产总成本、单位成本、来源入库凭证。
2. 订单成本与毛利：销售订单、客户、销售发票、开票数量、不含税收入、对应已开票数量的销售成本、毛利、毛利率。
3. 待核算项：人工未录入、成本未更新、发票未匹配交货、无法匹配销售成本、未完工工单。

暂定毛利＝开票不含税收入－对应已开票数量的销售成本。分批开票不得直接扣除整个工单成本。无法可靠匹配时标记“待核算”，不输出确定毛利；零收入时毛利率不可计算。

## 实现前还需核实

- 发票、交货、库存成本的明细关联，包括直接开票出库、分批交付、退货和跨期情况；采用库存实际销售成本还是其他匹配方式，需要结合单据逐笔核对，不以工单平均成本直接替代。
- 工单人工是否已进入制造入库估值，避免人工重复计入。
- 人工为零区分真实零、未录入和无需发生，状态不凭金额自动推断。
- 在制品及月结分配规则另行确认；首版不宣称支持完整月结。
- 只读查询优先新增接口和报表入口，保持现有订单成本归集、看板接口及核算流程不变。

预算、标准成本差异不作为本表首版的必要前提。本文件记录暂定口径，不代表财务最终核算规则或已完成上线。
