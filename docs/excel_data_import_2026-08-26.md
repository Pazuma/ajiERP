## 字段保留规则

Excel 没有标准 ERPNext 字段的列，统一保存在对应单据的 `custom_excel_*` 字段中；打开单据详情即可查看。物料编码、客户代码、供应商代码作为覆盖/匹配主键。实时库存是 Item 快照，不直接改写库存账，而是保存初期、入库、出库、实时数量、货位、单价、总值和盘点日期等快照字段。

## 校验与例外

- `工时记录.xlsx` 当前只有表头（工单号、姓名、部门、日期、开始时间、结束时间、总工时），没有数据行，因此没有创建虚假 Timesheet。
- 汇总计算、各项指标汇总或看板数据属于计算/展示数据，保持只读，不导入。
- 销售订单、采购、库存出入库、付款等标准单据受 ERPNext 的客户、供应商、物料、仓库、公司、账户、日期和重复单据校验约束。缺失的物料/客户/供应商会先按代码补建或通过自定义 Excel 字段保留原值；重复单据不强行制造第二张单据。
- Data Import 任务和日志保留在系统中，可按文件名查看成功、部分成功和失败行。失败行应先补齐对应基础资料，再使用同一任务以“Update Existing Records”或针对新单据的“Insert New Records”重跑。

## 后续导入约定

保持现有表头和列顺序即可。新增字段先增加 `custom_excel_` 字段并在 `config/excel_import_tables.json` 与 `data_import.py` 的表头映射中登记，再迁移站点。导入后通过列表页和单据详情核对：表头字段至少显示主键/日期/状态，详情中显示所有 Excel 扩展字段。
