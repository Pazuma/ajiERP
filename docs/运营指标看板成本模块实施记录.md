# 运营指标看板成本模块首版实施记录

日期：2026-10-16。对应《运营指标看板成本模块增量建设方案》。本次按方案的数据可用性分期实施，不新增核算、记账、标准快照采集或单据回写。

## 已实现效果

- 顶部增加“成本”页签，按公司和起止日期独立加载；宽屏核心卡片一行四张，窄屏自动换行。
- 财务参考收入、销售成本、毛利、毛利率及月度趋势明细：按总账过账日期、公司本位币读取，排除取消、期初和 Period Closing Voucher 分录。采用收入/销售成本科目类型作为明确标注的参考范围，并展示科目清单供财务核对。
- 产品制造入库成本：读取授权根工单对应的已提交 Manufacture 凭证成品金额，显示产品、库存单位、数量、金额、单位成本、凭证数；产品分页每页20项。不会叠加子工单成本。
- 预算执行率、返工报废占比、标准成本差异、料工费结构明确显示缺失原因；不使用当前 BOM 伪造历史标准，不填零、不错误着色。
- 成本独立 Excel 导出：口径与范围、成本指标、月度趋势、全量产品制造入库成本、参考科目范围五个工作表；比例按小数标明。导出不受当前显示页限制，禁止文本被解析为公式。
- 成本接口和导出统一校验财务角色、公司访问；父记录使用权限感知查询，子表仅读取已授权库存凭证。超过20000行明确拒绝并要求缩小日期，不输出截断汇总。
- 处理快速切换页签、筛选及延迟响应，避免成本数据覆盖老页签。原汇总和导出服务端接口保持不变。

## 调用与影响

成本页签 → `operations_kpi_cost.get_cost_dashboard_data` → 财务角色/公司校验 → 只读成本服务 → GL Entry、Account、Work Order、Stock Entry、Stock Entry Detail → 独立渲染。

成本导出 → `operations_kpi_cost_export.export_cost_dashboard` → 相同权限与只读服务 → 五个工作表。

只影响运营看板新增分支及成本只读查询。未修改业务单据、成本重算、库存估值、老汇总接口、老导出接口、数据库结构或 hooks。
