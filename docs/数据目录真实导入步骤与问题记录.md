## 2. 通用操作步骤

每张可导入表单均按以下步骤执行：

1. 打开 `http://127.0.0.1:8300/login`。
2. 输入 `Administrator` 和站点密码，点击登录，等待进入 Desk。
3. 进入对应模块和目标表单的列表页。
4. 点击右上角“菜单”按钮，选择“导入”。
5. 在“导入 <表单>”弹窗确认推荐模板名称和目标表单。
6. 点击“添加文件”。系统会再打开文件上传弹窗，不是直接完成上传。
7. 在上传弹窗选择目标 `.xlsx` 文件，点击“上传”。
8. 等待系统解析，查看“文件已解析，可以开始导入”或“请先处理预览中的警告”。
9. 检查字段表头、行数、关联单据和枚举值；有错误时不提交。
10. 截图并写入结果 JSON；关闭上传弹窗和导入弹窗。

Playwright 自动化脚本：[playwright_batch_excel_import.mjs](/home/cst/frappe_docker/development/frappe-bench/apps/client_akivision/docs/playwright_batch_excel_import.mjs)。本次脚本还保留了各表单的预览截图 `real_import_*.png`。

## 6. 问题清单与解决顺序

### 5.1 已确认的问题

1. 上传入口是两步：点击“添加文件”后还必须在上传弹窗点击“上传”。
2. 部分 Excel 含说明行、未命名列、宽表交货计划或非标准工作表结构，导致解析失败。
3. Link 字段不能使用显示名称或不存在的编码；项目、销售订单、采购入库、固定资产均因此被拦截。
4. Excel 中文状态/付款类型与系统枚举不一致，必须先做枚举映射。
5. Sample Loan Out/In 列表没有显示导入菜单，需检查迁移是否执行、缓存是否刷新以及 Administrator 的 Import 权限。

### 5.2 建议解决顺序

1. 先导入并确认 Customer、Supplier、Payment Terms Template。
2. 创建缺失的 User、Item、Department、Employee 及供应商编码，或在导入副本中改为已存在值。
3. 修正产品状态和付款类型枚举，重新上传预览。
4. 重做采购清单、工时记录的标准导入副本，保证一行表头、无合并单元格、无说明/汇总区。
5. 修正采购入库和销售订单的 Link 后，再处理业务单据。
6. 修复样品单据入口后，单独验证借出、借回和归还状态流转。
7. 每批预览无错误后才允许点击“开始导入”；提交后核对导入任务、单据数量和重复数据。
