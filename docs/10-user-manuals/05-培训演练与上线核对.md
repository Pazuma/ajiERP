# aki_erp 培训演练与上线核对

[返回手册目录](README.md)

本册供关键用户和讲师使用，普通员工可直接使用第 3 节问题速查和第 4 节反馈模板。

## 1. 建议培训顺序

| 顺序 | 内容 | 学完应会什么 |
|---|---|---|
| 第一步 | 阅读 01，讲师演示登录、搜索、草稿与提交 | 能找到单据，正确解释当前状态 |
| 第二步 | 按岗位阅读 02 或 03 | 能完成本岗位常用记录并检查结果 |
| 第三步 | 用 04 的流程一或二联合演练 | 知道上游来源和下一岗位要接收什么 |
| 第四步 | 练习异常、分批、退货和权限问题 | 不重复建单，不通过改数量或权限绕过问题 |
| 第五步 | 关键用户记录差异并修订培训资料 | 手册入口与正式启用范围一致 |

培训数据统一加易识别标记，演练前确认环境。培训过程中生成的库存和财务记录由培训负责人统一核对，不能自行删记录来清理。

## 2. 各岗位练习与验收

| 岗位 | 练习任务 | 通过标准 |
|---|---|---|
| 所有人 | 查一张指定订单，说明状态，打开来源和附件 | 单号、对象、日期、状态解释正确 |
| 资料维护 | 查重并准备一组客户、物料、单位和仓库 | 无重复，业务单据可选中，规格单位一致 |
| 销售 | 建 10 件订单，查草稿，再完成 4＋6 分批交付跟进 | 能找出每次送货及剩余量，不重复创建 |
| 采购 | 从缺口找申请、核对报价并创建订单，整理对账交接 | 来源、价格、交期和数量可核对 |
| 质量 | 登记 100 件中 90 合格、10 不合格 | 检验依据完整，可分别衔接入库与退货 |
| 仓库 | 办一张合格入库、一张调拨，解释盘点差异 | 来源及仓库正确，库存流水与实物一致 |
| 生产 | 查工单材料需求、领料及生产入库 | 完工量与库存相符，能指出未完成或缺料项 |
| 项目／研发 | 查节点、关联业务和费用，说明预算与实际 | 责任人清楚，依据可追溯，不混用预算成本 |
| 报价人员 | 核算一个多批量报价，导出客户版 | 税价与分摊正确，无内部成本泄露 |
| 样品管理员 | 3 件借出、2 件归还、1 件转销售 | 序列号唯一，借还与销售没有重复库存影响 |
| 财务／出纳 | 核对一组交接，形成应收或应付，办理分次收付核销 | 单据有效、凭据真实、余额正确，无重复记账 |
| 税务财务 | 识别或手工登记税票，核对抵扣和底稿 | 与原件一致，所属期正确，缺项不当零 |
| 销售总监／提成财务 | 确认方案、核实回款分配及一次发放台账 | 来源、版本、额度和凭据一致 |
| 负责人 | 查一项看板指标并回到来源 | 能解释日期口径、状态及差异处理人 |

验收不要只看“按钮能点”。每项至少检查：记录可找到、关键字段正确、来源可追溯、状态能解释、数量金额可核对、下一岗位能接收。

## 3. 常见问题速查

| 问题 | 自己先检查 | 仍未解决交给谁 |
|---|---|---|
| 没有某个模块／按钮 | 当前工作区、个人权限、单据是否已保存／提交、功能是否启用 | 业务负责人及支持人员 |
| 搜不到客户或物料 | 名称、型号、公司、启用状态和筛选；是否从结果中选中 | 资料维护人员 |
| 列表没数据 | 日期、公司、负责人、状态、仓库和数据权限 | 本模块关键用户 |
| 提交失败 | 逐字阅读原始提示，核对必填、来源、库存、检验和期间 | 对应岗位关键用户 |
| 订单未生成备货草稿 | 已有草稿、可分配库存、BOM、后台提示及状态 | 仓库／生产计划及支持人员 |
| 账面有库存却不能发货 | 可分配量、仓库、占用、批次／序列号、质检状态 | 仓库负责人 |
| 到货了但库存没增加 | 收料是否仅登记、质检是否完成、入库是否已提交、仓库是否正确 | 仓库及质量 |
| 工单完成却没有成品 | 完工进度与生产入库是否分别完成，入库仓库及状态 | 生产计划及仓库 |
| 采购对账无法提交 | 来源收货、重复占用、币种、供应商确认金额、差异附件 | 采购关键用户及财务 |
| 对账后没有结算草稿 | 对账类型、依据、确认状态、结算规则、剩余范围及已有草稿 | 销售关键用户及财务 |
| 已收钱但发票仍欠款 | 收款是否提交、客户与币种是否一致、是否分配到这张发票 | 出纳及财务 |
| 发票识别不准 | 原件清晰度、方向、税号、数字及重复提示，必要时手工复核 | 税务财务及支持人员 |
| 看不到成本或毛利 | 岗位是否需要该权限；销售业务入口是否能正常用 | 财务负责人及管理员 |
| 报表与业务数字不同 | 日期依据、单据状态、退货、币种、筛选及权限 | 报表口径负责人 |
| 税费计算表缺项 | 有无有效来源、所属期、人工值与依据；不是直接填 0 | 税务财务 |
| 点击后页面一直等待 | 先等结果、刷新、查是否已生成，不连续重复点击 | 支持人员 |
| 档案生成失败 | 保留错误信息、结账单号、期间及已有快照状态 | 财务及支持人员 |

## 4. 问题反馈模板

> 账号／岗位：____  
> 所属环境（培训／正式）：____  
> 模块、单据类型及单号：____  
> 操作时间（年月日时分）：____  
> 操作步骤：1. ____；2. ____；3. ____  
> 预期结果：____  
> 实际结果和原始提示：____  
> 是否已生成关联单据及其单号：____  
> 影响范围和期望处理时间：____  
> 截图／附件：____

截图保留页面标题、单号和原始提示，按接收人的授权遮挡客户敏感信息、价格和银行账号；不要发送密码或访问密钥。

## 5. 正式发放前由关键用户核对

本文编写时未逐页登录目标正式站点。以下是手册验收事项，由关键用户现场核对并记录结果，不要求普通员工自行排查配置。

| 核对范围 | 要验证什么 | 建议负责人 |
|---|---|---|
| 登录与环境 | 正式登录地址、培训地址、账号找回和支持渠道 | 支持人员 |
| 岗位入口 | 销售、采购、质量、仓库、生产、项目、财务账号能找到对应入口 | 各模块关键用户 |
| 基础资料 | 销售产品与物料映射、单位换算、仓库和供应商价格关联 | 资料、采购及工程 |
| 工作流 | 哪些单据走审批、实际按钮、审核角色和退回方式 | 部门负责人及管理员 |
| 备货分流 | 库存满足、部分满足、缺 BOM 三种情形的实际结果 | 销售、仓库及生产 |
| 采购质量 | 收料、检验、部分合格入库、未入库退货及待退仓退货 | 采购、质量及仓库 |
| 库存／生产 | 调拨、盘点、领退料、工序和生产入库的实际入口及影响 | 仓库及生产 |
| 项目／研发 | 研发申请入口、节点模板、驱动规则和成本权限 | 项目及财务 |
| 对账结算 | 客户送货／往来口径、草稿生成条件、结算创建正式应收 | 销售及财务 |
| 采购财务交接 | 跟进单接收、收货关联、开票限制和付款状态查询 | 采购及财务 |
| 报价与提成 | 版本确认、客户版导出、本人提成可见和发放台账边界 | 报价、总监及财务 |
| 样品 | 借入借出、归还、转销售及库存联动，尤其避免重复出库 | 样品管理员及仓库 |
| 中国财务 | 制审分离、凭证编号、冻结期间、税票识别和进项抵扣 | 财务负责人 |
| 报表和关账 | 科目映射、现金流、税费底稿、结账检查、快照及档案 | 财务负责人 |
| 可选扩展 | OA、海外成本、MES、外部 CRM、AI 实际是否开放 | 相应业务负责人及支持人员 |

对尚未启用功能，在员工培训中明确不演示其正式提交；启用范围变化后更新手册版本和适用岗位。
