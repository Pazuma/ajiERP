# aki_erp 新手入门与日常操作

[返回手册目录](README.md)

## 1. 第一次使用前准备什么

向公司指定的支持人员领取登录地址和个人账号，确认所属公司、部门、负责仓库及可用模块。网址与联系人由公司发放，不使用其他同事的账号。

首次练习使用培训环境。请先确认页面属于哪个环境，再新建订单、出入库或收付款记录。

## 2. 登录和找到入口

1. 在浏览器打开公司提供的网址，输入自己的账号和密码。
2. 进入首页后，按业务切换“销售、采购、库存、生产、项目、中国财务”等工作区。
3. 从侧边栏打开需要的列表或页面。找不到时，使用顶部搜索输入单据名称，如“销售订单”。
4. 打开后先看页面标题、公司和筛选条件，确认没有进错模块。
5. 看不到某个模块，先联系负责人确认授权；不要借用别人的账号绕过权限。

密码忘记时使用站点已启用的找回功能，或联系支持人员。不要在问题反馈、截图或群聊中发送密码。

## 3. 如何查找一笔业务

例如，要找客户 A 本月未完成的销售订单：

1. 打开“销售订单”列表。
2. 设置客户为客户 A，日期为本月，按需要选择状态。
3. 结果为空时，检查日期、公司、负责人和状态；清除不必要的筛选后再查。
4. 点击单号进入详情，核对客户、产品、数量和日期。
5. 查看来源和关联单据，例如送货单、工单或发票。关联记录也要打开检查状态。

手里有单号时优先按单号查。列表看不到，不一定代表没有记录，也可能是筛选或数据权限限制。

## 4. 保存、提交和审批的区别

| 页面状态或动作 | 日常含义 | 下一步 |
|---|---|---|
| 新建、未保存 | 内容尚未形成可稳定查询的记录 | 填写后保存 |
| 保存、草稿 | 留下记录，可按权限继续编辑 | 核对资料，交审核或提交 |
| 提交 | 让单据进入正式业务处理；具体影响因单据而异 | 检查提交结果和后续单据 |
| 待审核、退回、批准等 | 仅在该单据配置审批时适用 | 按页面提供的工作流动作办理 |
| 已取消 | 原单不再按原状态执行，可能影响下游 | 查清关联记录，按授权纠正 |
| 已完成、已关闭 | 业务状态，具体含义看单据类型 | 核对数量、金额及相关凭据 |

不是每个资料表都有“提交”，也不是每张业务单都有审批。点击后以页面显示的实际状态为准，不凭按钮点过就认为完成。

## 5. 新建一张单据的共同方法

1. **先查重。** 按客户订单号、供应商送货单号、日期和物料，确认没人已经录入。
2. **优先从上游创建。** 例如从采购订单创建后续收货，保留业务来源。
3. **先填主信息。** 公司、客户或供应商、日期、币种、业务负责人。
4. **再填明细。** 选物料，填写本次数量、单位、价格、仓库及适用税率。
5. **补充依据。** 交期、用途、项目、合同或确认附件；页面必填项必须完成。
6. **保存后复核。** 看每行数量、合计、含税口径和来源是否正确。
7. **按权限提交或交审核。** 出现错误时保留原始提示，解决后再继续。
8. **确认结果并交接。** 记录单号、状态、下一岗位和待办事项。

关联字段必须从搜索结果选择已有资料；输入名称但未选中，可能并未真正建立关联。资料缺失时找资料维护人员补建，避免同一客户或物料出现多个近似名称。

## 6. 分批业务怎么填

一张订单 10 件，本次只发 4 件：本次送货单填 4 件，后续再对剩余 6 件办理。不要再次照抄订单总量。

每次收货、送货、完工、开票或结算前，都要同时检查：原数量、本次已办理数量、此前已办理数量和剩余数量。不同环节分别累计，已送货数量不能当作已开票或已收款数量。

## 7. 金额、税率和单位怎么核对

| 容易混淆的内容 | 核对方法 |
|---|---|
| 件、箱、套、米、千克 | 看订单单位与库存单位、换算关系；不能只看数字 |
| 含税价与未税价 | 先确定合同口径，再看税额与总额；税率由财务确认 |
| 人民币与外币 | 看币种及汇率方向，不能直接比较不同币种的数字 |
| 交期与单据日期 | 交期是要求完成时间，单据日期是本次业务记录日期 |
| 空白与 0 | 空白通常表示未提供；0 表示核实后为零，不能随意互换 |

## 8. 附件、打印和导出

1. 打开业务单据，使用页面的附件区域上传对应合同、送货凭证、检验记录等。
2. 上传后打开附件，检查内容清晰、完整，与当前单据一致。
3. 建议命名为“单号_资料类型_日期”，如“销售单号_客户确认_20261027”。
4. 打印时选正确格式，预览客户、数量、金额、页码和明细，再打印或保存 PDF；有些专用页面使用自己的导出按钮。
5. 对外发送前核对版本、接收方和内容。客户版报价与内部成本表分开，不向客户发送材料成本、毛利或内部采购价格。

没有打印、导出或附件权限时，按公司授权流程申请，不用拍摄他人页面代替授权。

## 9. 填错了怎么办

**尚未提交的草稿：** 打开修改，重新保存；已有自动生成明细时，先确认修改是否会替换明细。

**已提交或已审核：** 先停止生成下游单据，把错误单号、错误内容和关联记录交给负责人。由有权限人员按实际功能取消、修订、退货或冲销，普通人员不直接改库存余额或账簿。

**重复单据：** 找出两张单的来源、状态及后续记录，先由负责人判断保留哪张，再处理。不要自行删除“看起来多余”的记录。

**系统卡住或提示后台处理：** 等待结果、刷新并查询是否已生成记录；不要连续点击创建或提交。

## 10. 跨部门交接怎么说清楚

每次交接至少包含：业务对象、来源单号、本次单号、本次数量或金额、当前状态、未完成事项、附件位置。

可直接复制以下文字：

> 交接对象：____；来源单号：____；本次单号：____。本次处理：____；剩余：____。当前状态：____；待你处理：____。附件位置：____；异常或差异：____。

## 11. 每天下班前检查

- 今天发生的业务是否已经录入，是否还停留在草稿。
- 待本人审核、退回补充和提交失败的单据是否已跟进。
- 已提交单据是否能查到正确的后续记录，是否重复生成。
- 已到货未检、已检未入库、已发货未对账等交接事项是否已告知下一岗位。
- 正式业务与培训数据是否分开，导出文件是否交给正确人员。
