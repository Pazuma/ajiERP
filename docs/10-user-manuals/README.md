# aki_erp 非技术人员使用手册

版本：1.2｜更新日期：2026-11-05｜适用对象：销售、采购、仓库、质量、生产、项目、财务及部门负责人。

这套手册按“先学共同操作，再查岗位模块，最后练完整业务”组织。无需懂编程或系统部署。文中“物料”包括原材料、半成品和成品；“单据”指系统内的一条业务记录。

直接阅读或打印：[打开离线合订版](aki_erp非技术人员使用手册-合订版.html)。用浏览器打开即可，无需登录系统或联网；左侧目录可跳转，浏览器“打印”可另存为 PDF。

## 使用口径

本版插入 12 张 Playwright 实际系统截图，并配有看图操作步骤。截图采集于 2026-10-29 的本地可访问站点，均为新建未保存表单；橙色边框、序号和底部指引为后加讲解标注。截图用来识别字段位置，不表示业务已保存、提交、审批、出入库或收付款。未显示的下方字段需滚动查看，提交后的业务按钮请按正文操作说明识别。不同岗位的菜单、按钮及默认值可能不同。

本文依据当前工作区业务应用源码、菜单配置和已有测试记录编写，未对目标正式站点逐页操作验收。菜单显示、是否启用、字段必填和审批人员受账号及站点设置影响。培训前由关键用户按 05 核对；员工使用时以当前页面提示和已批准的公司制度为准。

文中“搜索名称”是找不到菜单时的备用方式。括号内英文仅帮助精确搜索，不要求记忆。例如“销售订单（Sales Order）”。专用页面可能不会出现在全局搜索中，需通过对应工作区进入；找不到时反馈支持人员。

已知定制模块均在本套手册中列明。外部 CRM、MES、AI 助手和海外成本属于需确认启用及配置的扩展，单独说明使用边界；不把应用目录存在当作正式可用。人事薪资、固定资产、售后等通用 ERPNext 扩展未在本次资料中确认启用，不虚构为 aki_erp 的日常必用流程。

最重要的共同规则：保存不等于提交，提交不等于审批通过，到货不等于合格入库，对账不等于收付款，税费底稿确认不等于税务申报成功。
